# SERTZ v1.0.2 KNOWN ISSUES (알려진 이슈)

1. **환경 롤백으로 인한 원본 에셋 소실** — 2026-09-08 컨테이너 스냅샷 교체 사고로
   유저 제공 원본 에셋 팩(research/ cainos·vefects·Hovl Studio Magic effects pack)의
   디스크 보존분이 소실됐다. 게임에 통합된 추출물(webp/ogg — rune_circle, slash_arc,
   cfxr 계열 등)은 전부 git에 커밋돼 있어 게임 기능에는 영향이 없다. 원본이 필요하면
   유저 소지분 재업로드가 필요하다. (git 제외 원인: GitHub 100MB 파일 한도)

2. **현금 패키지 실결제 미실측** — STORE_PACKS 3종(성장/성장+치장/시즌)은 코드·UI·지급
   구성까지 구현됐으나, Play Console 인앱 상품 등록 전에는 실결제 테스트가 불가능하다.
   상품 등록 후 purchaseStorePack() 흐름 실측 필요. 결제 영수증의 서버 검증(RTT)은
   미구현 — 현재는 스토어 결제 콜백 신뢰 모델 (위변조 방지를 위한 서버 검증은 다음 사이클 권장).

3. **게임 상태 클라 권위(client-authoritative)** — 세이브가 localStorage 단일 트러스트라
   루팅 기기에서 재화/레벨 변조가 가능하다. v1.0.2에서는 서버 검증이 가능한 영역
   (계정/거래판/관리자/레이트리밋/감사/랭킹 상한)을 먼저 강화했고, 전투/재화의 전면
   서버 이관은 아키텍처 개편 사항으로 별도 사이클이 필요하다.

4. **AdMob 테스트 단위 ID** — 광고 단위 ID가 구글 공식 테스트 ID. 실수익화 시
   ADMOB_REWARDED_ID 교체 필요 (ads.ts 상단 주석 참조).

5. **SNS OAuth 키 미등록** — 구글/카카오/네이버 로그인은 키 등록 전까지 자체 가입/로그인으로
   동작 (env 주입 시 무코드 활성화 — accounts/index.js SNS 게이트).

6. **Keystore 저장 위치** — 서명 키가 레포에 커밋돼 있다(초기 세팅 유지). Play 앱 서명 사용
   시작 시 레포 제거 + 히스토리 청소 권장. 비밀번호 평문 노출 — CI 시크릿 이관 권장.

7. **GitHub 토큰** — remote.origin.url에 토큰 포함 상태 지속. 재발급 권고.

8. **테스트 도구 한계** — 헤드리스 뷰포트 최소값 제한으로 851×391 초소형 가로 실측은
   2340×1080 기준으로 대체 검증했다 (Safe Area CSS는 별도 적용 완료).

9. **보스 페이즈** — 페이즈 1~3(HP 66/33% 기준, 보스별 고유 패턴 풀, 카오스 지원군)은
   v4.1.4에 이미 구현돼 있어 v1.0.2에서는 시각 구분(툰 림라이트 — 카오스 붉은 림)만 보강했다.
