# SERTZ v1.0.2 CHANGELOG (versionCode 67)

버전 체계: 1.0.n 증분 (v1.0.1 → v1.0.2) · 세이브 그대로 유지 · 덮어설치 가능

## 버그 수정

1. **보스 등장 컷씬 카메라** — 기존엔 카메라가 보스를 바라본 뒤 약 0.8초 고정 타이머로
   플레이어 시점에 복귀해 "대사가 끝나기 전에 컷씬이 끝나는" 문제가 있었다.
   → 대사 종료 이벤트(`resumeFromDialogue`)를 기준으로 카메라를 보스에 고정하고,
     종료 후에만 보간(pan 620ms)으로 복귀. 20초 자가치유·이미 본 대사 경로도 동일 정합 보장.

2. **무릉도장 허수아비 무한 납작/부풀음** — 타격 스쿼시 트윈이 연타로 중단되면 중간 스케일이
   새 기준으로 캡처돼 누적 왜곡됐다. → 생성 시점 기준 스케일 1회 캡처(baseSX/baseSY)로
   근본 수정, 일반 몬스터 스쿼시도 동일 적용.

3. **EERT 큐브 연타 다중 소모** — 1클릭=1소모가 맞지만 처리 잠금이 없어 연타 시 이벤트가
   큐잉돼 큐브가 연속 소모됐다. → 260ms 처리 잠금으로 차단.

4. **등급업 큐브 사용 불가** — 사용 로직은 존재했으나 진입 UI가 없는 죽은 기능이었다.
   → 인벤토리 장비 탭에 [등급업 ×N] 버튼 신설 (장착 아이템, 전설 미만).

5. **0 르쯔 아이템 제거** — BM 아이템 47종 + 시작 장비 2종이 가격 0/판매가 0으로 표시됐다.
   → 전 아이템에 골드 기준가 부여(판매가 = 40%), sellValue의 BM 레전드 0 처리 제거.
     보스 드롭 9종은 의도적으로 거래소 전용(판매 UI 자체가 숨김).

6. **아이템 이미지 중복 32그룹 → 0그룹** — 엘릭서 아이콘을 HP/MP 7~10티어가 공유하는 등
   서로 다른 122종이 같은 아이콘을 사용했다. → 고유 색조·배지 적용 아이콘 90종 신규 생성
   (scripts/gen_unique_icons.py), data.ts icon 필드 일괄 갱신.

7. **NPC 초상화 불일치** — "헬의 문지기 가름" 등 화자-초상화 매핑 누락.
   → 보스명 토큰 매칭 자동화 + 시조 4계열(마르테/세이렌×2/로크) 명시 매핑 +
     DialogueDef.portraitId 옵션 신설(명시 지정 우선).

8. **세이브 복원 NaN** — atk/maxHp 무가드 대입으로 불완전 세이브에서 HP "NaN/NaN",
   공격 NaN. → 숫자 검증 후 복원으로 수정.

## 시스템 개선

9. **물약 상점 분류** — 일반 물약 6~10티어를 일반 상점에 판매(엘릭서는 특수 소모품으로
   BM 전용 유지). 상점 카테고리를 회복 물약/기타 소모품/장비/버프/펫/치장으로 세분화.
10. **마을 BGM 다양화** — 9챕터 마을이 5곡 순환(중복 발생)이던 것을 챕터별 고정 트랙 표로
    재편(9챕터 전부 상이 + 실내는 전용 트랙 title3/4 분리).
11. **니플헤임 밝기** — 암전 알파 0.48→0.28 완화, 챕터별 횃불 광원 프로필 신설(니플헤임
    1.75배), 횃불 축소 하한 40%→55%. 분위기 유지 + 가독성 확보.
12. **툰 셰이더 스타일** — 플레이어/보스 스프라이트에 ColorMatrix(대비/채도) + Glow
    림라이트 부착(Phaser 4 Filters). 카메라 후처리가 아닌 스프라이트 단위라 모바일 비용
    최소, fxLevel 0(적응형 저사양)에서 자동 해제/복원.
13. **치장 외형 적용** — 치장 착용 시 캐릭터 본체가 치장색으로 물드는 오버레이 레이어 신설
    (Base/Cosmetic 장비 분리 — 능력치와 무관한 순수 외형).
14. **목표 자동 강화** — 목표 ★N 설정 시 도달까지 자동 반복(골드 부족·최고강화·목표 도달
    시 자동 종료, 강화 실패 하락은 재시도).
15. **시즌 패스 한번에 받기** — 도달 레벨의 미수령 보상 전부 지급(중복/조건 미달 차단,
    프리미엄 미해금 시 무료 트랙만).
16. **업적 UI 개편** — 진행도 바(70/100 표시) + 수령 가능 금색 강조 + 전체/수령 가능/
    진행 중/수령 완료 필터 탭.
17. **집/여관 밸런스 분리** — 집(무료)=풀회복, 여관(20G)=풀회복+공/방 버프 60초.
    기존엔 무료인 집이 여관의 상위호환이었다.
