## v2.1 새 기능
- **친구 시스템**: 게임 내 `F`키(또는 우측 친구 버튼) → 내 고유번호(6자리) 확인·복사
  → 친구 코드 추가 → 접속 중이면 초록 불 + 현재 구역 표시 + **이동(따라가기)** 버튼
- **멀티플레이 안정화**: 서버 2초 하트비트 동기화 — 접속 순서와 무관하게 서로 보임
- **NPC 상호작용 프롬프트**: 대상(NPC·건물) 머리 위에 붙어서 따라다님
- **타일맵 자연화**: 물결형 도로 경계 + 숲 군집 배치
- 파티(Y): 미연결 시 안내 문구 표시

## 멀티플레이 (APK ↔ PC)
1. PC에서 웹 버전이 열리는 **서버 주소**(https://preview-… )를 복사
2. APK 타이틀 화면 우하단 **🌐 버튼** (첫 실행 시 자동 열림) → 주소 붙여넣기 → 저장 & 새로고침
3. 버튼이 초록 **"서버 연결됨"**이 되면 PC와 같은 서버 — 채팅·파티·친구 모두 연동
4. 친구와 서로의 코드를 등록하면 접속 시 자동으로 온라인 표시

## 설치 방법 (갤럭시 기준)
1. 폰 브라우저에서 위 링크로 APK 다운로드
2. APK 탭 → "알 수 없는 앱 설치" 허용
3. 기존 v2.0이 설치되어 있어도 그 위에 덮어쓰기 설치됩니다 (세이브 유지)
