 SERTZ v1.2.0 — 구글/카카오/네이버 소셜 로그인 OAuth 키 발급 및 적용 가이드
════════════════════════════════════════════════════════════════════

게임 계정 패널의 [구글로 로그인] [카카오로 로그인] [네이버로 로그인] 버튼을
실제로 동작하게 하려면, 각 플랫폼에서 OAuth 2.0 클라이언트 키를 발급받아
게임 서버 환경변수로 등록해야 합니다.

□ 소요 시간: 플랫폼당 약 5~10분
□ 필요한 것: 각 플랫폼 개발자 계정, 게임 서버 주소 (예: https://sertz4.space-z.ai)

────────────────────────────────────────────────────────────────────
 0. 원리 (어떻게 동작하나)
────────────────────────────────────────────────────────────────────

· 게임 서버는 OAuth 2.0 "authorization code" 플로우를 그대로 구현해 두었다.
  - 로그인 시작:  /api/auth/sns/{google|kakao|naver}/start
  - 콜백:        /api/auth/sns/{google|kakao|naver}/callback
  · 콜백 주소는 접속 중인 서버 주소를 자동 따라간다 (예: https://서버주소/api/auth/sns/google/callback)
· 환경변수에 키가 등록되어 있으면 버튼이 곧바로 OAuth 동의 화면으로 이동하고,
  없으면 "미설정" 안내 페이지가 뜬다 (현재 상태 — /api/auth/sns로 확인 가능).
· 등록할 환경변수 (서버 재기동 시 적용):
  - 구글:  SERTZ_GOOGLE_ID     / SERTZ_GOOGLE_SECRET
  - 카카오: SERTZ_KAKAO_ID     / SERTZ_KAKAO_SECRET
  - 네이버: SERTZ_NAVER_ID     / SERTZ_NAVER_SECRET

────────────────────────────────────────────────────────────────────
 1. 구글 (Google Cloud Console)
────────────────────────────────────────────────────────────────────

① https://console.cloud.google.com 접속 → 상단 프로젝트 선택 → [새 프로젝트]
   프로젝트명 예: SERTZ  → 만들기
② [API 및 서비스] → [OAuth 동의 화면]
   - User type: 외부 선택 → 만들기
   - 앱 이름: SERTZ · 사용자 지원 이메일 입력 · 개발자 연락처 입력 → 저장
   - 범위(Scopes)는 기본(email, profile, openid) 그대로 → 저장
③ [API 및 서비스] → [사용자 인증 정보] → [+ 사용자 인증 정보 만들기] → [OAuth 클라이언트 ID]
   - 애플리케이션 유형: 웹 애플리케이션
   - 이름: SERTZ Web
   - 승인된 리디렉션 URI (정확히 입력, 끝 슬래시 없이):
       https://[서버주소]/api/auth/sns/google/callback
       예) https://sertz4.space-z.ai/api/auth/sns/google/callback
       - 로컬 테스트 서버가 있으면 http://localhost:3000/api/auth/sns/google/callback 도 추가
④ 생성 완료 팝업의
   - 클라이언트 ID   → SERTZ_GOOGLE_ID
   - 클라이언트 보안 비밀번호 → SERTZ_GOOGLE_SECRET
⑤ [게시 상태]가 "테스트"면 등록한 테스트 사용자만 로그인 가능 → 정식 오픈은 [앱 게시] 눌러 "프로덕션" 전환
   (민감 범위를 안 쓰므로 구글 심사 없이 게시 가능)

────────────────────────────────────────────────────────────────────
 2. 카카오 (Kakao Developers)
────────────────────────────────────────────────────────────────────

① https://developers.kakao.com 접속 → 로그인 → [내 애플리케이션] → [애플리케이션 추가하기]
   - 앱 이름: SERTZ · 회사명 입력 · 저장
② [앱 키] 메뉴의  REST API 키  → SERTZ_KAKAO_ID
   (네이티브 앱 키 아님! 반드시 "REST API 키")
③ [제품 설정] → [카카오 로그인] → 활성화 설정 ON
   - Redirect URI 등록: [카카오 로그인] → [Redirect URI] 항목에
       https://[서버주소]/api/auth/sns/kakao/callback
④ [카카오 로그인] → [동의항목]
   - 닉네임: 필수 동의 (게임 닉네임 생성에 사용)
   - 프로필 이미지/이메일: 선택 (이메일은 앱 검수 필요 — 안 해도 닉네임만으로 로그인 가능)
⑤ [보안] 메뉴 → [클라이언트 시크릿 코드 생성] → 발급된 코드 → SERTZ_KAKAO_SECRET
⑥ 참고: 카카오는 기본적으로 보안비밀번호(클라이언트 시크릿)를 쓰지 않아도 되지만,
   본 게임 서버는 토큰 교환 시 secret을 함께 보내므로 반드시 ⑤를 발급해 등록할 것.

────────────────────────────────────────────────────────────────────
 3. 네이버 (NAVER Developers)
────────────────────────────────────────────────────────────────────

① https://developers.naver.com 접속 → 로그인 → [Application] → [애플리케이션 등장]
   - 애플리케이션 이름: SERTZ
   - 사용 API: [네이버 로그인] 체크
   - 제공 정보 선택: [닉네임] 체크 필수 (이름/이메일/성별/연령대/생일은 선택)
   - 환경 추가: [PC웹]
     · 서비스 URL:            https://[서버주소]
     · 네이버아이디로 로그인 Callback URL:
         https://[서버주소]/api/auth/sns/naver/callback
   - 등록하기
② [Application] → 내 애플리케이션 → [API 설정] 탭의
   - Client ID     → SERTZ_NAVER_ID
   - Client Secret → SERTZ_NAVER_SECRET
③ 검수 상태: 개발 중에는 등록한 테스트 계정만 로그인 가능
   → 정식 서비스는 [멤버십 설정]의 테스터 제한 해제 + 앱 상태 "서비스 적용"

────────────────────────────────────────────────────────────────────
 4. 서버 적용 (환경변수 등록)
────────────────────────────────────────────────────────────────────

서버를 실행하는 셸/서비스 관리자에 환경변수로 넣고 서버를 재시작한다.

  예시 (Linux systemd):
    sudo systemctl edit sertz
      [Service]
      Environment=SERTZ_GOOGLE_ID=1234567890-abc.apps.googleusercontent.com
      Environment=SERTZ_GOOGLE_SECRET=GOCSPX-xxxxxxxxxxxx
      Environment=SERTZ_KAKAO_ID=abcdef1234567890abcdef1234567890
      Environment=SERTZ_KAKAO_SECRET=AbCdEf1234567890
      Environment=SERTZ_NAVER_ID=xxxxxxxxxxxxxxx
      Environment=SERTZ_NAVER_SECRET=xxxxxxxxxx
    sudo systemctl restart sertz

  예시 (.env + pm2):
    SERTZ_GOOGLE_ID=...
    SERTZ_GOOGLE_SECRET=...
    SERTZ_KAKAO_ID=...
    SERTZ_KAKAO_SECRET=...
    SERTZ_NAVER_ID=...
    SERTZ_NAVER_SECRET=...
    $ pm2 restart server.js --update-env

  예시 (직접 실행):
    SERTZ_GOOGLE_ID=... SERTZ_GOOGLE_SECRET=... node server.js

적용 확인:
  curl https://[서버주소]/api/auth/sns
  → {"providers":{"google":{"configured":true},"kakao":{"configured":true},"naver":{"configured":true}}}
  configured: true 가 보이면 성공. 이후 게임 계정 패널의 각 버튼이 실제 동의 화면으로 이동한다.

────────────────────────────────────────────────────────────────────
 5. APK(안드로이드)에서의 동작 방식
────────────────────────────────────────────────────────────────────

· APK 웹뷰는 쿠키 세션이 유지되지 않아, SNS 로그인 성공 시 서버가
  콜백 URL 뒤 #auth_token=... 형태로 세션 토큰을 전달하고 클라이언트가
  localStorage에 저장해 Bearer 대신 URL 쿼리(?token=)로 API를 호출한다
  (v1.2.0 — CORS 프리플라이트 없이 동작, 구버전 배포 서버와도 호환).
· 앱에서 구글 로그인 시 "브라우저 열기"가 아닌 웹뷰 리디렉션으로 처리되며,
  로그인 완료 후 자동으로 게임으로 복귀한다.
· 주의: 구글 정책상 웹뷰 OAuth가 차단될 수 있다. 그 경우 콜백이 실패하면
  앱이 기기 기본 브라우저로 열어 처리한다(서버 코드 변경 불요).

────────────────────────────────────────────────────────────────────
 6. 자주 겪는 문제 (FAQ)
────────────────────────────────────────────────────────────────────

Q1. 버튼을 눌렀는데 "미설정" 안내 페이지가 뜬다
    → 서버 환경변수가 안 들어갔거나 재시작 안 함. /api/auth/sns로 configured 확인.
Q2. 구글: "리디렉션 URI 불일치" 오류
    → Google Console에 등록한 콜백 URI가 서버 주소와 1글자라도 다름 (https/http, 포트, 경로).
       반드시 https://[서버주소]/api/auth/sns/google/callback 그대로 등록.
Q3. 카카오: -401 client_secret 오류
    → 클라이언트 시크릿을 발급하지 않았거나 SERTZ_KAKAO_SECRET에 잘못 넣음.
Q4. 네이버: "등록되지 않은 Callback URL"
    → 애플리케이션 API 설정의 Callback URL 오타 확인 (경로 대소문자 포함).
Q5. 로그인했는데 닉네임이 "모험가"로 저장됨
    → 카카오 동의항목에서 닉네임 미동의 / 네이버 제공정보에 닉네임 미체크.
       각 콘솔에서 닉네임 제공을 켜면 다음 로그인부터 정상 저장.
Q6. 보안 주의
    · Client Secret은 절대 공개 저장소/클라이언트 코드에 넣지 않는다 — 서버 환경변수만.
    · 키 유출 의심 시 각 콘솔에서 즉시 재발급 후 환경변수 교체.
