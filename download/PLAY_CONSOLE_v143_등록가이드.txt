■ 1. 서명키 등록 (Play App Signing)
────────────────────────────────────────────────────────────────
APK는 아래 릴리스 키스토어로 서명되어 있습니다.
  파일: android/sertz-release.keystore (저장소에 백업 보관 필수!)
  별칭(alias): sertz
  유효기간: 2054-01-15까지

▶ Play Console 등록 방법:
  1) Play Console → 해당 앱 → 테스트/프로덕션 → 새 버전 만들기
  2) "앱 서명" 섹션에서 Google Play 앱 서명 사용(기본값) →
     업로드 키로 이 키스토어를 선택하면 자동 등록됩니다.
  3) 최초 업로드(AAB/APK) 1회만 하면 이후 같은 키로 서명된 파일만 받습니다.

▶ 인증서 지문 (Play Console "업로드 키 인증서" 등록/확인용):
  SHA1  : 2E:AD:70:14:E0:0A:8E:46:DC:87:8B:93:1A:8A:5E:EC:4C:5F:15:27
  SHA256: CC:77:4F:34:90:B1:E9:8D:87:4E:03:EF:0B:EB:E4:30:32:C2:05:A9:21:09:9E:1C:81:0B:09:E5:BD:E5:33:51
  MD5   : B7:0E:16:76:DD:27:32:00:03:79:48:17:1F:5E:48:E8

▶ 지문 직접 확인 명령 (키스토어가 있는 PC에서):
  keytool -list -v -keystore sertz-release.keystore -alias sertz

※ OAuth(구글/카카오/네이버 로그인) 앱 등록 시에도 위 SHA1을 요구하면
  이 값을 넣으면 됩니다.

■ 2. 광고 ID 선언 (Android 13 / API 33 경고 대응)
────────────────────────────────────────────────────────────────
이 앱은 AdMob SDK를 번들하지 않아 광고 ID를 사용하지 않습니다.
매니페스트에 이미 선언 완료:
  <uses-permission android:name="com.google.android.gms.permission.AD_ID"
      tools:node="remove" />
→ 어떤 라이브러리가 광고 ID 권한을 병합하려 해도 최종 APK에서 제거됩니다.

▶ Play Console 답변 (정책 → 앱 콘텐츠 → 광고 ID):
  "앱이 광고 ID를 사용하나요?" → 【아니요】 선택
  (향후 AdMob을 넣어 광고를 붙일 때는 이 선언을 "예"로 바꾸고
   매니페스트의 tools:node="remove" 줄을 제거한 뒤 재배포)

■ 3. 데이터 보안 섹션 답변표 (정책 → 앱 콘텐츠 → 데이터 보안)
────────────────────────────────────────────────────────────────
질문: 앱에서 필수 사용자 데이터 유형을 수집하거나 공유하나요?
  → 【예】 (계정 로그인·클라우드 세이브·랭킹 기능 때문)

질문: 수집하는 모든 사용자 데이터를 암호화하여 전송하나요?
  → 【예】 (모든 통신 HTTPS 강제 — 앱이 http 주소를 자동 https 승격)

질문: 사용자가 데이터 삭제를 요청할 수 있는 방법을 제공하나요?
  → 【예】

질문: 계정 생성 방법 (해당 항목 모두 선택):
  → 【사용자 이름 및 비밀번호】 (자체 회원가입/로그인)
  ※ SNS(OAuth) 로그인은 코드 준비 완료 상태(키 등록 전) — 활성화하면
    "OAuth" 항목을 추가로 선택

수집 데이터 유형 상세 (각 항목별):
  · 개인정보 — 사용자 ID(아이디/닉네임): 수집 ● 공유 ✕ / 목적: 계정 관리
    · 저장: 전송 중 암호화 ●, 삭제 요청 가능 ●
  · 개인정보 — 기타 사용자 데이터(클라우드 세이브): 수집 ● 공유 ✕
    / 목적: 앱 기능(백업/복원)
  · 앱 활동 — 앱 내 활동(게임 랭킹 기록): 수집 ● 공유 ✕ / 목적: 앱 기능
  · 기기 기타 — 진단(감사 로그·IP): 수집 ● 공유 ✕ / 목적: 보안·남용 방지
  · 위치/연락처/사진/금융/광고 ID: 수집 안 함

질문: 계정 삭제 URL (스토어 등록정보에 표시):
  → https://sertz4.space-z.ai/support
   (페이지 내 "계정 삭제" 버튼 + "데이터 삭제 요청" 문의 폼 제공.
    서버 계정·클라우드 세이브·랭킹·거래소 등록분 즉시 파기.
    기기 세이브는 같은 페이지 "기기 데이터 즉시 삭제"로 셀프 삭제 가능)

질문: 개인정보처리방침 URL:
  → https://sertz4.space-z.ai/privacy

■ 4. 서버 운영 체크리스트 (데이터 보안 답변 유지 조건)
────────────────────────────────────────────────────────────────
· 게임 서버(sertz4.space-z.ai)는 HTTPS로만 노출 — http 리스너 제거 유지
· 문의 데이터는 서버 db/support-inbox.jsonl에 적재 — 주기적으로 확인:
  ssh 후 `tail db/support-inbox.jsonl` (JSONL 1줄=1건)
· 계정 DB(db/accounts.json)는 GitHub 자동 백업 사용 중 — 백업에도
  비밀번호 해시만 저장되어 원문 노출 없음
