# SERTZ HTML 게임 시연 영상 + 인게임 에셋 소개 PPT 제작 프롬프트

> 이 프롬프트만으로 AI 슬라이드 제작 도구(예: Gamma, Tome, Microsoft Designer, SlidesGPT 등)에 입력하면 완성형 PPT가 나오도록 작성된 지시서입니다.
> 주제: SERTZ(이그드라실: 아홉 왕국) HTML5 모바일 MMORPG 시연 영상 + 인게임 에셋 소개
> 분량: 약 12–15장 슬라이드
> 언어: 한국어
> 비전: "고전 RPG 감성 + 현대 모바일 최적화 + 픽셀아트 + 폭넓은 에셋 다양성"

---

- **프로젝트명**: SERTZ (이그드라실 : 아홉 왕국)

- **시연 영상 길이**: 60–90초 (짧은 트레일러형) + 30초 인게임 에셋 쇼케이스

### 비디오 사양
- 해상도: 1920×1080 (16:9) 또는 1080×1920 (9:16 모바일 시연)
- 코덱: H.264 (mp4) + VP9 (webm) 폴백
- 비트레이트: 4Mbps (품질 vs 용량 균형)
- 길이: 각 30초 × 3개 = 90초 총 시연

1. 게임 화면 녹화 — OBS Studio 60FPS
2. 시연 영역 자르기 — HandBrake (1080p, 30fps)
3. 자막 입히기 — FFmpeg (한국어 자막 burn-in)
4. 트랜지션 입히기 — DaVinci Resolve (crossfade 200ms)
5. 출력 — mp4 + webm 2개
