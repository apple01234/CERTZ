■ ① 랭킹 — 노무현 제거 [즉시 완료]
───────────────────────────────────────────────────────────────
· 대상: fantasticpie 계정의 세이브(playerName=노무현, lv17 레인저)
· 조치: CERTZ-DB에서 세이브 항목 삭제 → 라이브 랭킹 즉시 반영 확인
  (https://sertz.vercel.app/api/rank → 해당 항목 소멸)
· 계정 자체는 남아 있음(완전 삭제 아님). 그 유저가 다시 접속해
  같은 닉네임으로 세이브를 올리면 랭킹에 재등장 가능 → 재등장 시
  말씀 주시면 "계정 삭제 + 닉네임 필터"로 더 강하게 막아드립니다.

■ ② 구글 로그인 안됨 [원인 확정 — 콘솔 설정 필요]
───────────────────────────────────────────────────────────────
원인 실측 결과, 코드 문제가 아니라 Firebase 프로젝트 설정이
비어 있어서 로그인 창 자체가 열리지 않는 상태였습니다.

  · Firebase 인증 백엔드(Identity Toolkit API)가 꺼져 있음 (403 확인)
  · 앱에 google-services.json 이 없음 → 네이티브 구글창 실패 (확정)
  · 앱 코드 쪽은 vc125에서 보완 완료 (설정 들어오면 바로 동작)

▶ 운영자(유저) 콘솔 작업 — 딱 5분, 아래 순서대로:

  [1] https://console.firebase.google.com 접속 → 프로젝트
      "sertz-681eb" 열기
  [2] 왼쪽 메뉴 "빌드 → Authentication" → "시작하기" 클릭
      → 로그인 방법에서 "Google" → 사용 설정 토글 ON
      → 지원 이메일 선택 → 저장
      (이 단계에서 인증 API가 자동으로 켜집니다)
  [3] 상단 "프로젝트 설정(톱니바퀴) → 일반" 탭 →
      "내 앱"에서 [Android 아이콘] 클릭
        - Android 패키지 이름: com.sertz.myapp
        - 앱 닉네임: SERTZ (아무거나)
        - 디버그 서명 인증서 SHA-1: 아래 값 복사-붙여넣기
          2E:AD:70:14:E0:0A:8E:46:DC:87:8B:93:1A:8A:5E:EC:4C:5F:15:27
          (SHA-256도 물어보면:
          CC:77:4F:34:90:B1:E9:8D:87:4E:03:EF:0B:EB:E4:30:32:C2:05:A9:21:09:9E:1C:81:0B:09:E5:BD:E5:33:51)
  [4] 같은 화면에서 "google-services.json 다운로드" 클릭
  [5] 그 파일을 이 대화방으로 전달 (첨부)
      → 파일 투입 후 재빌드(vc126)해서 구글 로그인 완성

※ [5] 대신 파일을 android/app/ 폴더에 직접 넣어도 되지만,
  빌드는 이쪽에서 하므로 대화방 전달이 가장 편합니다.
※ 구글 로그인은 그 전까지 자체 계정(아이디+비번)으로 대체됩니다.
