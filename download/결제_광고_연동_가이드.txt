  SERTZ — 결제·광고 실연동 가이드  (v1.0.1-beta / vc122 기준)

이 릴리스(v1.0.1-beta)부터 결제(구글 플레이 인앱)와 광고(AdMob 보상형)가
실동작 가능한 상태로 코드에 완전히 연결돼 있다. 남은 것은 "콘솔 등록"뿐 —
아래 순서대로 등록하면 실제 수익이 발생한다. (코드 수정 불필요)

2. Play Console — 인앱 상품 등록 (필수, 30분)
────────────────────────────────────────────────────────────────────
  Play Console → 수익화 → 제품 → 인앱 상품 → "상품 만들기"로 아래 7개 등록.
  ※ 상품 ID는 오타 없이 정확히 (코드와 일치해야만 결제창이 열린다)

  [에메랄드 충전 — 유형: 관리되는 제품(소모성)]
   상품 ID              이름                가격(권장)
   sertz_gem_10        에메랄드 10개       ₩1,100
   sertz_gem_55        에메랄드 55개       ₩5,500
   sertz_gem_120       에메랄드 120개      ₩11,000
   sertz_gem_300       에메랄드 300개      ₩27,500

  [현금 패키지 — 유형: 관리되는 제품(비소모성)]
   sertz_pack_growth_19800        성장 패키지          ₩19,800
   sertz_pack_growth_cos_29900    성장+치장 패키지     ₩29,900
   sertz_pack_season_15900        시즌 패키지          ₩15,900

  ※ 상품 활성화는 "AAB가 업로드된 앱"에서만 가능 — v1.0.1-beta AAB를
    내부 테스트에 올린 직후 등록하면 된다.
  ※ 테스트: 수익화 → 설정 → 라이선스 테스터에 본인 지메일 추가 →
    테스터 결제는 실제 청구 없이 시뮬레이션된다.

────────────────────────────────────────────────────────────────────
3. AdMob — 앱 등록 & ID 교체 (필수, 20분)
────────────────────────────────────────────────────────────────────
  1) https://apps.admob.com → "앱 추가" → Android → "Google Play에서 앱 찾기"
     → SERTZ 선택 (패키지 com.sertz.myapp)
  2) "광고 단위" → "보상형 광고 단위" 추가 → 이름: 에메랄드 보상
  3) 발급된 2개 ID를 코드에 붙여넣고 재빌드:
     · 앱 ID     (ca-app-pub-XXXXX~XXXXX 형태)
       → android/app/src/main/AndroidManifest.xml 의
         com.google.android.gms.ads.APPLICATION_ID value 교체
     · 보상형 단위 ID (ca-app-pub-XXXXX/XXXXX 형태)
       → src/game/ads.ts 의 ADMOB_REWARDED_ID 교체
  ※ ID 교체 전에도 테스트 ID로 광고가 실제로 내려오고 보상도 지급된다
    (테스트 광고는 수익 0원 — 테스터에게는 이 상태로 충분).
  ※ Play Console "광고 ID" 선언: 앱 콘텐츠 → 광고 ID → "예"(광고 목적 사용)로
    변경 필요 (v1.0.1-beta부터 AD_ID 권한을 사용한다).

────────────────────────────────────────────────────────────────────
4. 결제 테스트 절차 (라이선스 테스터 기기에서)
────────────────────────────────────────────────────────────────────
  ① 내부 테스트 트랙에서 v1.0.1-beta 설치 → 게임 부팅
  ② 상점(라고스) → 에메랄드 충전소 → ₩1,100 젬 구매
     → 결제창(테스터 카드) → 완료 → "에메랄드 +10 충전 완료!"
  ③ 같은 상품 재구매 → 또 결제됨 (v1.0.1-beta에서 고친 재구매 차단 버그 확인)
  ④ ② 진행 직후 앱을 강제 종료 → 재부팅 → "미지급 결제 복구" 팝업 확인
  ⑤ 패키지 1종 구매 → 구성품 지급 확인 → 앱 삭제 후 재설치 → 재지급(복원) 확인
  ⑥ 광고 무료 상자 / 광고 보상 버튼 → 테스트 광고 시청 → 보상 지급 확인

6. v1.0.2-beta — AdMob 실제 ID 적용 (ads.txt 완료 / 앱 ID·단위 ID 대기)
────────────────────────────────────────────────────────────────────
  이미 완료된 것:
  · ads.txt + app-ads.txt 배포 (public/ads.txt, public/app-ads.txt)
    → https://sertz.vercel.app/ads.txt 에서 확인 가능
    → 라인: google.com, pub-5675573589406258, DIRECT, f08c47fec0942fa0

  아직 대기 중인 것 (콘솔에서 값 2개만 복사하면 끝):
  · AdMob 콘솔(https://admob.google.com) → 내 앱 → SERTZ 선택
      ① 앱 ID        = ca-app-pub-5675573589406258~NNNNNNNNNN  (앱 설정)
      ② 보상형 단위 ID = ca-app-pub-5675573589406258/MMMMMMMMMM  (광고 단위 → 보상형 추가)
  · 받으면 1발 교체:
      python3 scripts/patch_admob_ids.py "앱ID" "단위ID"
    → AndroidManifest.xml + src/game/ads.ts 동시 교체, 다음 빌드부터 실제 수익 광고
  ※ 현재는 구글 테스트 ID로 안전 부팅 중(잘못된 앱 ID 넣으면 앱 전체 크래시 —
    콘솔 복사값 그대로만 넣으면 됨). 테스트 ID 상태로도 출시·심사는 문제 없음.

7. v1.0.2-beta — 구글 통합 로그인(OAuth) 실연동
────────────────────────────────────────────────────────────────────
  구현: Firebase Authentication (구글 공급자)
  · 웹: Firebase JS SDK 팝업 로그인 / 앱: @capacitor-firebase/authentication 네이티브 구글창
  · 서버: POST /api/auth/google — Firebase ID 토큰 RS256 서명검증(fbverify) 후
    기존 계정 DB에 g_ 접두 자동 가입 → 자체 계정과 동일 세션 발급
    (클라우드 세이브·거래소·랭킹 전부 그대로 호환)

  유저가 해야 할 일 (Firebase 콘솔 https://console.firebase.google.com):
  ① 프로젝트(sertz-681eb) → Authentication → 시작하기 → Sign-in method →
     "Google" 공급자 사용 설정 (지원 이메일 선택)
  ② 프로젝트 설정 → 일반 → 내 앱 → Android 앱 추가:
     · 패키지명: com.sertz.myapp
     · SHA-1: cc774f34... (아래 명령으로 확인 가능)
       keytool -list -v -keystore android/sertz-release.keystore
     → google-services.json 다운로드 → android/app/google-services.json 저장
  ③ (웹 팝업용) Authentication → Settings → 승인된 도메인에 sertz.vercel.app 추가

  ※ google-services.json이 없어도 앱은 정상 빌드·부팅된다(Firebase만 비활성).
    파일 투입 즉시 구글 로그인 활성화(build.gradle 조건부 플러그인).
  ※ 제공해준 AIzaSy... 키는 Firebase 웹 API 키로 웹 SDK에 반영 완료.
