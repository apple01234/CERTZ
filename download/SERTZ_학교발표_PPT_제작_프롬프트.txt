- 발표자: [이름] / [학년 반]
- 발표 시간: 5~8분
- 청중: 같은 학교 학생 + 선생님 (게임을 만들어 본 적 없는 사람이 대부분)

[발표 목적]
1. 내가 만든 게임을 소개하고 실제로 플레이 가능한 완성작임을 보여주는 것
2. 게임 개발에 어떤 기술이 쓰였는지, 어떤 문제를 스스로 해결했는지 보여주는 것
3. "친구들도 지금 바로 폰에 설치해서 해볼 수 있다"는 것을 전달하는 것

[게임 기본 정보 — 사실 그대로 사용]
- 게임 이름: SERTZ: 이그드라실
- 장르: 2D 탑다운 뷰 액션 MMORPG (메이플스토리 모바일 스타일의 감성)
- 플랫폼: 안드로이드 APK (웹 버전도 존재)
- 최신 버전: v1.4.9 (versionCode 101 — 정식 버전 101번째 빌드) — 보스 9종 아트·애니메이션 전면 리뉴얼 포함
- 개발 기간: 학교 수업 외 시간에 약 [기간] 개월, 총 40번 넘는 업데이트 릴리스
- 개발자: 나 혼자 (기획·프로그래밍·밸런스·버그 수정 전부 1인)

[기술 스택 — 슬라이드 1장으로 정리]
- 게임 엔진: Phaser 4 (HTML5 게임 엔진) + TypeScript
- 웹 프레임워크: Next.js + React + Tailwind CSS (UI 오버레이)
- 맵 제작: Tiled(타일맵 에디터), 캐릭터: SPUM 에셋
- 앱 패키징: Capacitor 8 → 안드로이드 APK
- 서버: Node.js + Socket.IO (실시간 멀티플레이·파티·친구·랭킹·클라우드 세이브)
- 데이터: 자체 계정 시스템(비밀번호는 scrypt 해시 저장) + GitHub 자동 백업
- 테스트: Playwright 기반 자동 E2E 테스트 (빌드마다 11개 항목 자동 검증)
- 배포: GitHub Releases를 CDN처럼 사용해 APK 즉시 다운로드 + 앱 안에 구버전 자동 알림

[게임 콘텐츠 규모 — 숫자로 임팩트 주기]
- 직업: 4대 계열, 1차~5차 전직 포함 28개 클래스 (전직 시련·각성 연출 포함)
- 스테이지: 9개 챕터 90개 구역 + 환생 후 "재림의 땅" 15구역
- 보스: 스토리 보스 9종 × 난이도 4단계(이지/노말/하드/카오스) + 재림 보스
- 시스템: 스타포스 강화, 유니온(배치·레이드), 시즌 패스, 반려동물, 치장(코스튬 20종 이상), 거래소, 왕국 랭킹, 몬스터 파크, 무한의 탑 등
- 오디오: BGM 40트랙 + 효과음 140종 (기능마다 소리를 다르게 설계)
- 코드 규모: 게임 코어 파일 하나가 12,000줄 이상, 전체 수만 줄

[개발 과정에서 실제로 해결한 문제 — "어려웠던 점" 슬라이드용]
1. 스프라이트가 갑자기 안 보이는 버그 → 로딩 실패 자동 재시도(3회) + 텍스처 무결성 감사 체계(texGuard)를 만들어 자가 수복
2. 저사양 폰에서 프레임 드랍 → 적 AI를 거리별 3단계로 스로틀링, 오브젝트 풀링, 자동 저사양 모드 전환으로 해결
3. 유저(베타테스터)들이 겪는 버그 리포트 13건 → 하나씩 재현·수정하고, 같은 버그가 재발하지 않게 자동 테스트를 만듦
4. 해킹·어뷰징 방지 → 보안 헤더, 접속 출처 화이트리스트, 서버 검증, 비밀번호 해시 등 서버 보안을 단계별 강화
5. UI가 화면을 너무 차지하고 서로 겹치는 문제 → 겹침 원인을 좌표로 분석해 UI를 모달 방식으로 재편

[최신 업데이트(v1.4.8) 하이라이트 — "꾸준히 발전시키고 있다" 증거용]

- 사운드: 38개 기능이 같은 효과음을 공유하던 것을 기능별 전용 소리로 전면 분리 + BGM 크로스페이드
- 보안: 웹 표준 보안 헤더(CSP 등) 도입, 클라우드 세이브 서버 검증, 멀티플레이 관리자 플래그 위조 차단
