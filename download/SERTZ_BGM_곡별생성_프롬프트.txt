■ 사용법
 · 아래 프롬프트는 Suno / Udio / Stable Audio 등 음악 생성 AI에 그대로 붙여넣어 사용한다.
 · 각 곡마다 프롬프트가 완전히 다르다 (장르·템포·악기·무드 전부 상이).
 · 생성 후 반드시 [파일 규격]에 맞춰 변환해서 넣는다.
   - 파일명: 아래 표기 그대로 (예: bgm_boss1.ogg)
   - 위치: public/assets/audio/ (웹서버) — 게임이 구역 진입 시 자동 로딩
   - 포맷: OGG(Vorbis) 권장 — audio.ts가 assets/audio/{키}.ogg를 fetch한다
   - 길이: 60~120초 이상 권장, 끝→처음 자연 루프(페이드아웃 없음)
 · 보스곡 9개는 챕터 1:1 매핑이며, boss6~9는 현재 boss1~4의 피치 변형 파생곡으로
   임시 운영 중이므로, 새로 만들면 그대로 교체 가능하다.

 ■ 적용 체크리스트 (곡 생성 후)
════════════════════════════════════════════════════════════════════
 1. 파일명 확인: bgm_{종류}{번호}.ogg (소문자, 공백 없음)
 2. 위치: public/assets/audio/ 에 복사
 3. 포맷 변환: ffmpeg -i 새곡.wav -c:a libvorbis -q:a 5 bgm_x1.ogg
 4. 루프 확인: 끝→처음 이어 재생 시 박자가 자연스럽게 이어지는지
 5. 서버 반영: git push 후 서버 재배포 (APK는 재빌드 불필요 — BGM은 서버에서 스트리밍)
 6. 보스곡 교체 시: 코드 수정 불필요 (같은 파일명이면 자동 적용)
