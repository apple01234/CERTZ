SERTZ v4.1.1 APK 다운로드 안내
================================

이번 버전 (v4.1.1, versionCode 48) — 앱 부팅 크래시 긴급 수정
- v4.1.0에서 광고 SDK 설정(AdMob 앱 ID) 누락으로 앱이 아예 안 열리던 문제 수정
- 광고 보상 + 구글 플레이 에메랄드 충전 기능과 UI는 그대로 유지
- 구글 플레이 인앱 결제 권한(BILLING) 정식 추가
- 광고는 현재 구글 테스트 광고로 내려옴 (실제 수익 연동 전 단계)
- 세이브 그대로 유지 · 덮어설치 가능

이전 버전 (v4.1.0, versionCode 47) — 바르가 업데이트
- 이벤트 구역(무릉도장/바르가 수비전/균열 던전) 나가기 검은 화면 근본 수정
- 무릉도장 타이머가 폰에서도 확실히 보이게 수정
- 설정창에 긴급 귀환 장치 — 가장 가까운 마을로 즉시 이동 (8초 쿨)
- 파티원의 스킬·공격이 내 화면에도 보임 (같은 구역 기준)
- 쿠폰 코드 입력 중 게임 단축키 완전 차단 (다른 창 안 뜸)
- 채팅창 접기/펼치기 버튼 (설정 저장)
- 바르가 수비전 도중 철수 시 보상 축소 정산 (무료 파밍 악용 차단)
- 포탈 위치 라벨 + 화면 밖 복귀 포탈 방향 가이드
- 스토리 토벌 퀘스트 목표 마릿수 상향 (5~12마리 → 13~30마리)
- 적응형 품질 — 프레임 낮으면 이펙트 자동 축소
- "이세카이" 명칭 변경: 바르가 수비전 / 균열 던전 / 바르가 원정대
