■ 방법 1 — 폰에서 바로 (제일 쉬움, 권장)
  게임 웹 주소 뒤에 파일명을 붙여 브라우저로 열기:
  https://sertz1234.space-z.ai/SERTZ-v3.0.28.apk
  → 즉시 다운로드 시작 (서버 직결)

■ 방법 2 — Windows (파일 패널에서 받기)
  1. 아래 4개 파일을 같은 폴더에 다운로드
     - SERTZ-v3.0.28.apk.part1 / part2 / part3
     - join_apk.bat
  2. join_apk.bat 더블클릭 → SERTZ-v3.0.28.apk 생성
  3. 폰으로 옮겨서 설치

■ 방법 3 — Mac / Linux
  파트 3개 + join_apk.sh 를 같은 폴더에 받고:  sh join_apk.sh

■ 직접 합치기
  Windows CMD:  copy /b SERTZ-v3.0.28.apk.part1+SERTZ-v3.0.28.apk.part2+SERTZ-v3.0.28.apk.part3 SERTZ-v3.0.28.apk
  Mac/Linux:    cat SERTZ-v3.0.28.apk.part1 SERTZ-v3.0.28.apk.part2 SERTZ-v3.0.28.apk.part3 > SERTZ-v3.0.28.apk

■ 검증 (선택)
  aapt: versionCode 41 / versionName 3.0.28 정상
  기존 세이브 그대로 이어서 플레이 가능 (v3.0.26 위에 덮어 설치)
