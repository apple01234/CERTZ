# APK 실기기 검증 체크리스트 (REVAMP_100 #30)

> 이 항목만은 **실기기 없이는 닫을 수 없다.** 코드·CI 는 이미 정상이므로
> 아래 절차대로 한 번만 돌리면 끝난다.
>
> 작성 vc288 · 소요 약 20분

## 0. 준비

| 필요한 것 | 확인 방법 |
|---|---|
| 안드로이드 기기 (Android 8.0+) | 설정 → 휴대전화 정보 |
| APK 파일 | GitHub Releases 에서 `SERTZ-vc261.apk` |
| JDK (빌드까지 할 경우) | `JAVA_HOME=/home/z/jdk` — 이 환경엔 없다 |

CI 는 `.github/workflows/android-build.yml` 에서 빌드된다(`runs-on: ubuntu-24.04` 고정).
Releases 에서 최신 APK 를 받아 쓰면 로컬 빌드는 필요 없다.

## 1. 설치

1. 기기에서 "출처를 알 수 없는 앱 설치" 허용
2. APK 실행 → 설치
3. 앱 실행 → 타이틀 화면이 뜨는지 확인

**합격 기준**: 검은 화면이 아니라 타이틀 로고가 보인다.

## 2. 회피 제거 확인 (안전영역)

> 노치·제스처바에 HUD 가 가리는 문제. 웹에서는 재현되지 않고 기기에서만 나온다.

1. 게임 시작 → 캐릭터 생성 → 인게임 진입
2. 상단 좌측 **LV 배지**와 하단 **채팅·기록 버튼**을 본다

**합격 기준**
- [ ] LV 배지가 상태바/노치에 가리지 않는다
- [ ] 하단 버튼이 제스처바에 가리지 않는다
- [ ] 스킬 버튼(우하단 원형)이 화면 밖으로 나가지 않는다

**불합격 시**: `src/app/globals.css` 의 `env(safe-area-inset-*)` 사용 여부 확인.

## 3. BGM 전환 청취

> 구역을 옮길 때 음악이 바뀌는지. 파일은 있는데 재생이 안 되는 경우를 잡는다.

1. 마을에서 10초 대기 (마을 BGM)
2. 차원문으로 필드 이동 (필드 BGM 으로 바뀌어야 함)
3. 보스 스테이지 진입 (보스 BGM)

**합격 기준**
- [ ] 세 곳의 음악이 **서로 다르다**
- [ ] 전환 시 0.5초 이상 무음이 길게 이어지지 않는다
- [ ] 효과음(공격·피격)이 BGM 에 묻히지 않는다

**불합격 시**: `src/game/audio.ts` 의 `BOSS_OF`/`BOSS_TRACKS` 와 실제 ogg 파일명 대조.
(`tests/bgm-coverage.test.mjs` 가 파일 존재는 이미 보증한다 — 문제는 재생 경로다)

## 4. 전투 기본 동작

1. 몬스터 3마리 처치
2. 스킬 1·2·3 각각 1회 사용
3. 물약 사용

**합격 기준**
- [ ] 데미지 숫자가 뜬다
- [ ] 스킬 쿨다운이 줄어든다
- [ ] HP 가 회복된다

## 5. 보스전 (선택, 5분 더)

세이브를 보스 스테이지로 바꾸려면 앱 데이터를 초기화하고 다시 진행해야 한다.
시간이 없으면 생략해도 된다 — 웹에서는 이미 검증됐다(`docs/VC288_PLAY_EVIDENCE.md`).
