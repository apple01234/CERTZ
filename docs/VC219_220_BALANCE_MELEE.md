# vc219~220 — RPG 밸런스 3건 + 근접 평타 전직 강화

## 1) 버프 퍼센트 합산화 (vc219)

`damageModel.ts` 의 버프 결합을 **곱 → 합**으로 바꿨다. 스킬 `agd-rpg` §1 권고
("Sum within a layer by default and reserve multiplicative stacking for a few rare effects") 적용.

```ts
// 종전
(스킬배율 × runSkl) * rage * rebirthDmgMult
// 현재
buffSum = (rage-1) + (rebirth-1) + runSkillPct/100   // 레이어 합산, 상한 2.0
최종    = 스킬배율 × (1 + buffSum)
```

- `1 + 합` 인 이유: 버프가 없을 때 정확히 0 이 되게 기준을 옮긴다(rage=1 → 0).
- `BUFF_SUM_CAP = 2.0`: 상한 근거는 아래 실측 참조.
- **호환**: 버프 1개만 걸린 경우는 종전과 완전히 같다. **2개 이상 겹칠 때만** 약해진다.

## 2) 보스 HP 상향 — **하지 않았다 (권고가 틀렸음)**

`docs/VC218_RPG_AUDIT.md` 에서 "최종 보스 HP 95,000 → 250,000" 을 권고했는데,
**그 전제가 완전히 틀렸다.** 실제 최종 보스 HP 는 95,000 이 아니라:

```
실효 HP = BOSS_DEFS.nagr.hp(95000) × r15 mul.hp(56) × 난이도 배율
  이지   2.25 →  11,970,000
  노말   4.50 →  23,940,000
  하드   7.20 →  38,304,000
  카오스 18.60 →  98,952,000
```

스케일이 3자리 달랐다. 제 감사는 `BOSS_DEFS` 의 기본값만 보고
**`mul.hp`(재림 배율)와 `BOSS_DIFFS`(난이도 배율)를 빠뜨렸다.**

그 결과 판정이 정반대가 된다:

| | 종전(곱) | 현재(합) |
|---|---|---|
| 노말 최종보스 | 631방 | 946방 |
| 예상 시간 | ~12분 | ~19분 |

**보스는 이미 충분히 단단했다.** HP 를 올렸다면 19분이 40분이 되어 더 나빠졌을 것이다.
따라서 2번은 **취소**하고 수치를 건드리지 않았다. 합산화로 -33% 약해진 것은
원래 편차(44배)를 줄이는 대가로 수용한다.

## 3) 세이브 스키마 버전 (vc219)

`SaveData.v?: number` + `SAVE_VERSION = 1` + `migrateSave()` 도입.

- `loadSave()` 에서 **기본값 채우기보다 먼저** 마이그레이션을 돌린다.
  (순서가 반대면 기본값이 변환 결과를 덮어쓴다)
- `v` 없는 세이브는 0 으로 간주 → 0→1 단계에서 승격. 데이터 변환은 없다(도입 시점).
- 규칙을 주석으로 못박음: **필드 추가만 하면 올리지 않고, 의미/단위가 바뀔 때만 올린다.**

## 4) 근접 평타 전직 강화 (vc220) — 사용자 지시

> "근접 직업 전직시마다 평타강화 확실히 되게하기 (수치만 강화가 아니라 이펙트도 강화)"

### 진단 — 수치도 부족했고 이펙트는 아예 없었다

| 축 | 종전 | 문제 |
|---|---|---|
| 데미지 | `(warrior?1.1:1.0) + 0.08*t` | 1→4차 **+20%** 뿐 |
| 참격 크기 | `warrior ? 1.15 : 1` | **tier 를 안 읽음** — 4차도 1차와 같은 크기 |
| 판정 폭 | `116` 고정 | 전직 무관 |
| 명중 VFX | `crit` 여부만 | 색만 바뀜 |

즉 **이펙트는 전직에 전혀 반응하지 않았다.** 이게 "이펙트도 강화" 지시의 핵심.

### 수정

**`Player.atkSlash()`**
```ts
tierK = max(0, sTier - 1)          // 1차=0 … 4차=3
fxK   = 1 + 0.11 * tierK           // 4차 1.33
dmgMul = (warrior?1.1:1.0) + 0.22*tierK... // 0.08 → 0.22
reach  = base * (1 + 0.035*tierK)  // 판정 사거리
hitW   = 116 * fxK                 // 판정 폭
knock  = base * fxK                // 넉백
slashScale = base * fxK            // 참격 스프라이트
```
1·2·3타 호출부 6곳을 모두 `slashScale`/`hitW` 로 교체.

**`WorldScene.spawnMeleeVfx(x,y,dx,dy,crit,tier)`** — tier 단계별 연출 추가
- 1~2차: 참격 궤적 (크기 `1 + 0.1*(tier-1)`)
- 3차+: **충격파 링** 추가 (타격이 화면에서 한 번 더 읽힌다)
- 4차+: **파편 버스트 + 미세 셰이크**

**`DriveFX.slashArc(..., scaleMul)`** — 궤적 크기 파라미터 신설.

## 남은 한계

- **원거리(궁수·해적)는 이번에 손대지 않았다.** 궁수는 이미 "N차 = N발" 래더가 있고

  이 환경은 `next build`/정적 검증까지만 가능했다.
