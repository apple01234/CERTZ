## 개편 후보 (미착수 — 우선순위 제안)

### 전투 손맛
- 피격 방향 표시기(화면 가장자리 붉은 호)
- 연속 처치 콤보 배너(3/5/10킬)
- 스킬별 화면 흔들림 강도 차등
- 보스 페이즈 전환 시 슬로우모션 0.15초
- 치명타 전용 사운드 레이어
- 처치 시 골드 흡수 연출

### 정보 설계
- 데미지 숫자 크기/색을 피해량 구간별 차등
- 상태이상 아이콘 HUD 표시
- 스킬 쿨다운 잔여 초 숫자 표시
- 미니맵에 퀘스트 목표 마커
- 현재 버프/디버프 남은 시간 바

### 편의
- 상점 다중 구매(10/50/MAX)
- 인벤토리 정렬·필터
- 스킬 프리셋 2~3개 저장
- 자동 물약 임계값 슬라이더
- 퀘스트 자동 추적 토글

### 콘텐츠
- 일일 보스 도전(주간 로테이션)
- 무한 웨이브 모드
- 협동 레이드(비동기 랭킹)
- 코스튬 수집 도감
- 업적 시스템
