## 2. 환경 메모 (이전 지시서의 "브라우저 안 뜸"은 이 환경에서는 틀리다)

- `npx next dev -p 3111` 은 뜬다. Chromium + Playwright 가 미리 깔려 있다
  (`createRequire(import.meta.url)('playwright')` 로 불러온다 — ESM import 는 못 찾는다).
- 신규 캐릭터는 도입 컷신 → 튜토리얼 상태로 들어간다. 스크립트에서는 `Escape` 로 컷신을 넘긴 뒤
  `window.__SERTZ_SCENE__` 로 상태를 읽는다. **튜토리얼 중에는 `gotoStage` 강제 이동이 먹지 않았다** —
  다른 지역 검증은 튜토리얼을 정상 완료하거나 기존 세이브를 주입해야 한다(아직 방법 미확립).
- `node server.js` / `next start` 는 시도하지 않았다.

## 3. 240 지시서 기준 다음 착수 순서

지시서의 "최우선 착수 목록" 그대로다. 이 세션의 조사 결과를 덧붙인다.

1. **121·122 궁극기 wave (vc284 `3561cce`)** — `Player.useSkill5` 의 wave 블록은 주석("총 피해는 늘리지 않는다")과 달리
   기존 직접 피해 **위에** 1타 0.35×(0.7~1.3)을 최대 24회 더한다(계수 합 약 8.4, 궁극기 배율 적용).
   판정은 플레이어 중심 반경 360 이고 hold(22~30초) 끝까지 이어져 종결기 뒤에도 피해가 난다.
   매 틱 `spawnBurstAt`+shake 도 붙어 있다(AGENTS "자주 호출 지점은 과하지 않게"와 충돌 소지).
   → 직업별 직접 피해 계수 합을 먼저 표로 뽑고(123), wave 를 그 예산 안으로 정규화하거나 종결 시각까지만 돌게 한다.
   `scripts/playtest-ult-waves.mjs` 가 있으나 **한 번도 실행되지 않았다** — 이 환경에서는 돌릴 수 있다.
2. **141·142 디오** — `BOSS_STAGE_STATS.howlrstone2x3 = 19,800` 이 실제 스폰에 적용되는지 브라우저로 확인(이 세션은 튜토리얼에 막혀 못 함).
   GM 체험·재림·탑·공동토벌은 표를 쓰지 않는다(의도). vc284 의 GM 3단 탐색 경로와 이중 배율 여부를 대조할 것.
3. **161·164 성장** — 경험치는 "장을 끝내면 다음 게이트 +1" 로 맞췄다. 반복 의뢰·탑·파크·경험치 책(레벨 요구치의 40~150% 고정)은
   손대지 않았다. 과하향/과상향 모두 실플레이로 확인 필요.
4. **201~207 기록전** — 재전송은 `submitWithRetry`. 지시서가 지적한 "409 성공 오판" 은 "응답 없는 요청 뒤의 409 만 성공 취급" 으로
   좁혀 두었다. 경기장 전환→시간 초과→복귀의 브라우저 재현이 남았다.
5. **021~027 로딩** — 측정 안 함. 로컬 dev 약 3초는 기준선이 아니다.
