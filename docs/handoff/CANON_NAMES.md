# CERTZ 명칭 정본 (CANON_NAMES)

> 정본 출처: `docs/handoff/evernote-approved/1.txt` ~ `8.txt` (이하 `N.txt:L` 형식으로 인용)
> 우선순위 규칙: **숫자가 작은 문서가 이긴다**(1 → 8). 앞 문서와 뒤 문서가 충돌하면 앞 문서를 채택하고, 뒤 문서 표기는 "표기 흔들림"으로만 기록한다(§11).
> 이 문서는 **기획서에 실제로 적힌 것만** 담는다. 문서에 없는 이름은 "없음"이라고 명시하며, 창작하지 않는다.
> 8.txt는 **19화까지만 공개**된 범위다. 그 이후(결말·최종 보스·최종 상태)는 어떤 형태로도 채우지 않는다(§9).
