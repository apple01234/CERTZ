# 기획서 인물 → 직업 설계 (vc192)

사용자 지시: "앞으로 대규모 업데이트를 할 때 기획서의 스토리의 주요 인물을 직업으로 낼 거야 (모험가와 별개의 직업)"

## 1. 설계 원칙

### 1-1. 두 개의 직업 계통 (분리 운용)

| 계통 | 정체 | 전직 방식 | 현재 구현 |
|---|---|---|---|
| **모험가(Adventurer)** | 플레이어가 처음 고르는 5계열 33직업 | 1차(Lv10) → 2차(Lv30) → 3차(Lv50) → 4차(Lv100) | 기존 (유지) |
| **인물(Hero)** | 기획서 등장인물 그 자체가 직업 | **각성(Anima)**: 스토리 진행 + 전용 재료로 해금 | **신규** |

### 1-2. 인물 직업은 "전직"이 아니라 "각성"

이유:
- 기획서 인물은 계보가 아니라 **서사로 강해진다** (루시 = 생명의 초월자, 아리 = 검의 초월자 등)
- 모험가 트리에 끼워 넣으면 "왜 전사가 루시가 되는가"라는 서사 모순이 생긴다
- 사용자 지시도 "모험가와 **별개의** 직업" → 별도 해금 경로가 맞다

### 1-3. 인물 직업의 3단계 = 기획서의 힘 등급

| 단계 | 기획서 근거 | 해금 조건 |
|---|---|---|
| **순력** (1단계) | 혈통·가문으로 얻는 힘 | 해당 인물 스토리 챕터 클리어 |
| **혼력** (2단계) | 원소의 구체가 선택 / 자각 | 전용 재료(원소의 구체) + Lv |
| **초력** (3단계) | 초월의 경지 | 초월 시련 + 전용 재료 |

이 구조면 기획서 설정과 100% 일치하면서 게임 성장 곡선도 자연스럽다.

## 2. 인물 → 직업 매핑 (1기 기준 8종)

무기·원소·능력이 기획서에 명시된 인물만 직업화한다.

| # | 인물 | 직업명 | 무기 | 원소 | 핵심 능력 (기획서) | 초월자 |
|---|---|---|---|---|---|---|
| 1 | 스칼렛 에델리오나 | **어둠의 군주** | 다크엑스칼리버 | 어둠 | 세뇌·핏빛세례·진정한 어둠의 군주 | — (보스) |
| 2 | 아리스텔라 데스티니(아리) | **검의 초월자** | 솔라플레임이그니션소드 | 불 | 태양의 불꽃 · 검의 수호자 | 힘(무기의 힘) |
| 3 | 루시페르 에크레디트(루시) | **생명의 초월자** | 무기 없음 | 자연 | 치유 · 제작 · 생명이 피어나는 연못 | 생명 |

## 3. 구현 계획

### 3-1. 데이터 구조

```ts
// lore.ts 또는 별도 hero.ts
export type HeroKey = "scarlet" | "ari" | "lucy" | "zer" | "riel" | "velika" | "ran" | "lilac";

export interface HeroClassDef {
  key: HeroKey;
  name: string;          // "검의 초월자"
  character: string;     // "아리스텔라 데스티니"
  weapon: string;        // "솔라플레임이그니션소드"
  element: ElementKey;
  grade: MasterGrade;    // 순력/혼력/초력
  unlock: { chapter: string; lv: number; item?: string };
  skills: { s1: ...; s2: ...; s3: ... };
}
```

### 3-2. 플레이어 상태 확장

```ts
// Player
heroClass: HeroKey | null;   // 각성한 인물 직업 (모험가 cls 와 별개 슬롯)
heroGrade: MasterGrade;
```

- 모험가 직업(`cls`)과 **동시 보유**한다. 전환은 자유(각성 후).
- 스탯은 "모험가 보너스 + 인물 보너스"로 합산하지 않고, **인물 직업 활성 시 인물 쪽으로 대체**한다(밸런스 붕괴 방지).

### 3-3. UI

- 전직관(카이엔)에 **"각성" 탭** 추가
- 각성 화면: 인물 초상화 + 무기 + 원소 + 해금 조건 + 스킬 미리보기
- 잠긴 인물은 실루엣 + 조건 텍스트

### 3-4. 스킬

각 인물당 3스킬(원소 어빌리티 / 영역 어빌리티 / 초월 어빌리티). 기획서에 명시된 능력명을 그대로 쓴다.
- 아리: 태양의 불꽃(원소) / 검의 수호자(영역) / 솔라플레임 이그니션(초월)
- 루시: 치유의 손길(원소) / 생명의 연못(영역) / 만개(초월)
- 제르: 주문 폭발(원소) / 뇌운(영역) / 페우스(초월)
- 리엘: 발도(원소) / 영역 전개(영역) / 도의 극(초월)

## 4. 범위 결정

이번 작업에서 **1기 인물 8종**을 직업으로 낸다. 각성 UI·데이터·스킬·전환 로직까지 완결한다.
2·3기 인물은 데이터만 등록하고 잠금 상태로 둔다(추후 확장).
