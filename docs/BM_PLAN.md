## 2. 수익 퍼널 설계 (SERTZ 여정)

```
타이틀 진입 → D0 온보딩(마을·첫 퀘스트) → 출석부 1일차 보상 (즉시 도파민)
→ D0~D3 첫 결제 창구: BM상점 스타터팩 하이라이트 (미구매 시에만 노출)
→ D1~D7 일일 루프: 일일 퀘스트 3종 + 광고 5회 + 시즌 패스 XP
→ D7~D30 성장 루프: 가챠 상자·패키지·스타포스·eert·성좌·룬
→ 결제 전환: GEM_SKUS 충전 → 에메랄드 → 가챠/버프/펫/치장/패스/구독
```

- 첫 결제 타이밍: BM 문서 권장(D0~D3)에 맞춰 **스타터팩을 BM상점 최상단에 고정 노출** (구매 시 자동 해제).
- 배틀패스 노출: BM상점 배너 + 혜택 창 버튼 — 레벨 10 전후 자연 노출 구조 (문서: "레벨 10~15 도달 시점에 노출").

## 6. LTV/CAC 시뮬레이션 (문서 공식: LTV÷CAC ≥ 1.5)

- 가정: MAU 1,000 · 페이율 3% · ARPPU ₩11,000(120💎) · 광고 ARPDAU $0.05 → 월 매출 ≈ (30명×₩11,000)+(1,000×$0.05×30×1,350₩/$) = ₩330,000 + ₩2,025,000… 광고 비중이 큰 초기 구조 → **미디에이션(애드몹+MAX) 연결이 선행 과제**.
- 유기적 유입(UA $0) 기준 LTV/CAC는 사실상 무한대 — 유료 UA 진입 시 설치당 $1.5 이하 유지 조건으로 시뮬 재계산.
- 실수령률: 스토어 30% 수수료 반영 시 ₩1,100 결제 → 실수령 약 ₩660~715. 웹샵 오픈 시 +10% 보너스를 줘도 실수령 +45%p 개선 → 웹샵이 최우선 마진 레버.

## 8. 도파민 설계 원칙 (dopamine driven development)

1. **변동 보상**: 가챠 상자는 구매 즉시 개봉 — 획득까지 무단계(창고 경유 0).
2. **FOMO 사이클**: 일일 특가(자정 교체) + 시즌 패스(매월 1일 리셋, 미수령 소멸 명시).
3. **수집 완결성**: 도감 43종·피규어 12종·성좌 36노드 — 마일스톤 보상 누적.
4. **진행 가시화**: 패스 XP 배너("Lv.N 달성!") · 수령 가능 보상 앰버 발광 · 출석 14일 그리드.
5. **연속 보상**: 출석 14일 사이클 대박 보상 · 일일 퀘스트 3종 수령 시 패스 XP +40 (이중 보상).
6. **소급 수령**: 프리미엄 패스 구매 시 도달분 전부 수령 가능 — "사면 손해" 없음 (결제 거부감 최소).
