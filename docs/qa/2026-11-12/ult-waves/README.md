## 읽는 법

1. **121 확인** — wave 는 주석("총 피해는 늘리지 않는다")과 달리 기존 피해 위에 더해진다. 증가폭은 직업별 +3% ~ +90%.
   wave 한 벌의 크기가 거의 같기 때문에(약 430~550) 직접 피해가 작은 직업일수록 비율이 커진다.
2. **122 확인** — 전 직업에서 직접 타격은 1.7~7초에 끝나고 wave 가 hold 끝(21~30초)까지 이어진다. 종결기 뒤에 피해가 계속 난다.
3. **새로 드러난 것** — 같은 조건에서 직접 피해 합이 439(seaking) ~ 16,788(deadeye)로 **38배** 차이 난다.
   단일 고정 표적 조건이라 광역형 직업이 불리하게 재졌을 수 있지만, 직업 간 예산이 맞춰져 있지 않다는 신호다(지시서 126~139).
4. wave 는 4차뿐 아니라 1~3차 궁극기에도 21~24회 붙는다(hold 6초면 간격 220ms). 직접 피해가 작은 하위 차수에서는 비율이 더 클 것으로 보이나 **재지 않았다.**
