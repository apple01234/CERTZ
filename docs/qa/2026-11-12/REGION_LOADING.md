# 첫 월드 준비: 지역별 로딩 1차 개선

기준 커밋: `9eb9923` (2.2.23 / 279). 아래는 최초 로딩 개선 시점의 검증 기록이다.
이 기록 당시에는 빌드·운영 배포·실기기 검사를 하지 않았다. 이후 사용자가 게임 외 UI 개선과 함께 커밋·푸시·Windows EXE 빌드를 요청했다. 후속 내용은 worklog.md를 따른다.

## 바뀐 범위

- 기존 BootScene 카탈로그·WorldScene 진입 구조를 그대로 사용한다.
- 처음부터 모든 외형을 기다리지 않고, 선택한 외형의 28프레임을 준비한다.
- 이야기 필드는 현재 지역 몬스터와 정예를 준비한다. 튜토리얼 연습 대상, 전직 시험 상대, 보스 소환수는 빠뜨리지 않는다.
- 탑·파크·수비전·공동토벌·마을 등 동적 소환 장소는 전체 몬스터를 준비한다.
- 다른 지역으로 이동할 때 같은 gate를 거치며 기존 캐시와 진행 중 요청을 재사용한다. 전체 카탈로그를 플레이 중 일괄 다운로드하지 않는다.
- 공통 효과·날씨·조명·컷신 배우·보스·소리·지형은 그대로 기다린다. 옛 선택 규칙의 레벨별 효과 생략은 되살리지 않았다.
- 외형 지연 로더의 `idle0` 조기 완료 판정을 제거했다. Player도 28프레임 전체가 준비된 뒤 외형을 적용하며, 그동안 기존 기본 외형을 보여준다.
- 저장 항목·밸런스·카메라·서사·원본 파일은 변경하지 않았다.

## 같은 조건의 전후 비교

개발 화면의 Chromium Canvas, 신규 게스트 캐릭터, 브라우저 캐시 해제,
지연 40ms·다운로드 초당 2,500,000바이트로 각각 측정했다.
시점은 캐릭터 선택 이후 WorldScene의 에셋 대기 시작부터 실제 초기화 완료까지다.
운영 평가의 92초와 다른 환경이므로 직접 비교하거나 개선 비율을 대입하지 않는다.

| 항목 | 변경 전 | 변경 후 |
| --- | ---: | ---: |
| 월드 준비 시간, 각 1회 | 43.101초 | 25.258초 |
| 먼저 기다린 카탈로그 정의 | 3,675개 | 1,313개 |

후속 PC 재검사에서도 26.120초 / 1,313개였다. 응답 본문 합계에는 타이틀·미리보기도 포함된다.
요청 수 감소가 주효했지만 파일 용량은 거의 그대로다. **10초 목표를 달성하지 못했다.**
공통 대형 효과를 안전하게 지연 로드하거나 무손실 묶음으로 줄이는 작업은 후속 과제다.

## 브라우저 검증

재현 스크립트: `scripts/playtest-region-loading.mjs`.
`REGION_QA_URL`, `REGION_QA_OUT`, `REGION_QA_MODES`, `CHROMIUM_PATH`로 대상과 검사 환경을 지정한다.
데스크톱은 Canvas, 모바일 크기/터치 환경은 WebGL을 검사한다. 각 검사는 독립 브라우저로 실행한다.

- PC 신규 캐릭터 생성 → 실제 월드 진입 성공. 공통 효과·라일락 배우·지형·선택 외형 확인.
- 아직 쓰지 않는 왕실 의상과 토끼는 최초 진입 중 요청되지 않음.
- 왕실 의상 변경: 준비 중 기본 외형 유지, 28프레임과 걷기 애니메이션 준비 후 적용.
- `startTransition()`으로 던전 10-3 → `dlcocean1` → 파크 → 시작 필드 이동 성공.
- 이동 시 준비 시간은 각각 162ms / 101ms / 2,110ms / 62ms였다. 캐시가 채워진 후의 수치이며 신규 전체 진입 시간으로 쓰지 않는다.
- 검사한 지역의 주요 오브젝트와 실제 적에서 `__MISSING` 텍스처 없음. 미처리 페이지 예외 없음.
- DLC 진입 검사는 테스트 캐릭터의 완료 플래그를 켜서 실행했으며, 실제 스토리 진행·해금 전체를 검증한 것은 아니다.
- 실제 던전 전투·보스전 품질과 컷신 카메라 복원은 이번 작업 범위 밖이다.

## 알려진 검사 환경 제한

- 처음 연속 실행한 모바일 WebGL 검사 탭이 종료됐다. PC 결과를 모바일 통과로 간주하지 않는다.
- 독립 브라우저로 재실행한 모바일 WebGL 검사도 240초 제한 안에 끝나지 않았다. 모바일 월드 진입·옷 변경·지역 이동은 **미검증**으로 남긴다. 개발 화면은 계속 열려 있으며, 검사 브라우저가 남아 있지 않은 것도 확인했다.
- 별도 `shot`으로 데스크톱·모바일 타이틀을 캡처했다. 기존 계정 저장 연결 값 부재로 계정 조회/이름 확인 요청이 실패하며, 개발용 방문 분석 스크립트도 기존 보안 정책에 막힌다.
- `/assets/maps/_index.json`의 선택적 맵 편집 덮어쓰기 목록은 이 작업 전부터 404이고 원래 맵으로 폴백한다.
- 위 계정/분석/편집 목록 문제를 이번 로딩 수정의 해결 결과로 보고하지 않는다. 미리보기 자체의 `preview.log`는 기록이 없었다.

## 코드 검사

- 최종 전체 검사 712/712 통과. 선택 로딩 검사 15개에는 지역 이동 캐시 재사용, 누락/재시도, 취소, 공통 연출 보존, 외형 28프레임 완료 대기가 포함된다.
- `tsc --noEmit` 및 변경된 게임 코드의 ESLint 통과. 검증 스크립트 문법 검사 통과.
- 테스트용 외부 임시 Python 환경에 Pillow와 NumPy를 갖춘 뒤 실행했다. 프로젝트 의존성은 추가하지 않았다. 과거 검사 환경의 타일 실패 2건을 이번 실행에 재인용하지 않는다.
- 사용자 지시에 따라 프로덕션 빌드·APK 빌드는 생략했다. 이번 변경의 커밋·푸시는 아직 실행하지 않았고 버전도 그대로다.
