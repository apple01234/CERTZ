## 1. 스킬 이펙트 3단이 "차고 → 내려찍고 → 터진다"로 읽히는가

**배경:** vc276 에서 이펙트를 `_c`(시전) / `_Dust`(먼지) / `_Hit`(타격) 3장으로 분리했습니다.
데스크톱 headless 실측은 시전 33ms / 먼지 100ms / 타격 183ms 로 벌어졌지만,
**손맛은 70ms 간격이 실제로 읽히는지에 달려 있습니다.**

| # | 확인 내용 | 판정 | 메모 |
|---|---|---|---|
| 1-1 | 기술을 쓰면 **차오르는 동작이 먼저** 보이는가 | [ ] 예 [ ] 아니오 [ ] 판정불가 | |
| 1-2 | 착지/타격 순간이 **시전과 구분**되는가 | [ ] 예 [ ] 아니오 [ ] 판정불가 | |
| 1-3 | 3단이 **뭉쳐서 한 덩어리**로 보이지는 않는가 | [ ] 뭉침 [ ] 구분됨 [ ] 판정불가 | |
| 1-4 | 재생 속도가 **너무 빠르다 / 적당 / 너무 느리다** | [ ] 빠름 [ ] 적당 [ ] 느림 | |

> 1-5 는 vc273 에서 고친 버그입니다(마무리가 최대 2,220ms 예약인데 즉시 호출되고 있었음).

## 3. 구역별 종족이 눈에 구분되는가

**배경:** vc277 의 `CreepZone` 이 개방 셀을 공간 구역으로 쪼개 종족별로 배정합니다.
vc278 에서 구역 크기와 종족별 반경을 균등화했습니다(반경 편차 49.5% → 4.3%).
**숫자는 좋아졌지만 "눈으로 구분되는가"는 별개 문제입니다.**

| # | 확인 내용 | 판정 | 메모 |
|---|---|---|---|

| 3-2 | 구역 경계가 **이동 중에 체감**되는가 (종족이 바뀌는 지점) | [ ] 체감됨 [ ] 모르겠음 | |
| 3-3 | 종족별로 **행동/색이 달라** 구분되는가 | [ ] 예 [ ] 아니오 | |
| 3-4 | 한 종족이 **맵 전체에 흩어져** 보이는 경우가 있는가 | [ ] 없음 [ ] 있음 (스테이지: ) | |
