# vc278 — CrossCode 데모 공개 데이터 분석 + 기본공격 대시 캔슬 적용

출처: 공식 웹 데모 v0.7.1 Beta(엔진 1.18a)가 브라우저에 내려받는 공개 데이터
(`data/players/lea.json`, `data/enemies/{buffalo,meerkat,hedgehog-boss}.json`).
**수치를 읽어 설계 원칙만 참고했다. 파일·그림·소리는 저장소/런타임에 복사하지 않았다.**

## 분류
- 아래 수치는 **데이터 파일 판독**이다. 실제 전투 화면 관찰이 아니다.
- 화면 관찰은 타이틀 → 모달 닫기 → New Game → `hideout.entrance` 플레이어블(엔티티 203)까지만 재확인했다.
  전투 장면은 여전히 **직접 보지 못했다**.

## 판독 결과
| 항목 | 값 |
|---|---|
| 대시 | 시작 즉시 무적, 속도 320 × (0.05+0.11)s, 이후 0.2s 대기. 처음 0.05s 충돌 무시 |
| 기본공격 / 투척 / 차지 투척 후 막힘 | `dash: 0` (즉시 대시 가능), 다음 행동 0.18~0.21s, 이동 0.3s |
| 콤보 마무리 | dash 0, 다음 행동 0.7s, 이동 0.8s — 큰 기술일수록 후딜이 길지만 대시는 항상 열려 있음 |
| 퍼펙트 가드 | 0.1s 창 |
| 기본 탄 / 차지 탄 | 속도 550 / 600, 피해계수 0.6 / 1.3, 차지 탄은 3회 반사 |
| 버팔로 돌진 | 1.0s 예고 후 1.4s 돌진, 실패 시 0.4s 빈틈, 벽 충돌 시 기절 |
| 버팔로 내려찍기 | 0.35s 예고 |
| 동시 공격 제한 | `ACTION_TOKEN`으로 동시에 공격하는 적 수를 제한, 공격 간격 4~7s |

## CERTZ 비교와 적용
- 이미 있음: 대시 무적(vc268 `iFrameMs`), 피격 경직 중 회피(vc268), 근접 예고 340ms(버팔로 0.35s와 유사).
- **적용(vc278)**: 기본공격 후딜(200~360ms) 중에도 대시 가능. 스킬은 그대로 잠김(시그니처 시전 시작 단계 캔슬만 기존 유지).
  캔슬하면 남은 연타 판정은 사라진다(대가). 기본공격마다 번호를 매겨, 캔슬된 공격의 지연 판정이
  다음 스킬/공격 중에 터지거나 그 상태를 끊지 않게 했다.
- 미적용 후보: 동시 공격 토큰(밸런스가 바뀌므로 사용자 확인 후), 돌진형 예고 480ms → 더 길게.
