# 게임과 독립된 제작 도구 페이지

- `/tools`: 두 제작 도구로 바로 들어가는 안내 페이지. 게임 엔진을 시작하지 않는다.
- `/editor`: 맵 메이커. 기존 단독 경로를 유지한다.
- `/skill-editor`: 스킬 에디터. 기존 단독 경로를 유지한다.
- 각 편집기 상단에 제작 도구 안내와 다른 편집기를 새 탭으로 여는 링크를 추가했다. 다른 편집기로 이동할 때 현재 편집 페이지를 닫지 않는다.
- 에디터는 원래 canvas 2D/React 도구다. 별도 Phaser 게임이나 축소 게임으로 다시 만들지 않았다. 계정·캐릭터 저장과 서버 지도 반영 권한도 바꾸지 않았다.

## 확인한 동작

로컬 Chromium에서 맵을 20×12로 변경해 JSON 저장, 15×9 새 맵 생성 후 저장 파일을 다시 불러와 20×12 복원, 스킬 문서 이름 변경·JSON 저장·불러오기를 확인했다. 두 페이지 모두 게임 scene/game 인스턴스와 Phaser 런타임 요청이 없었고, 테스트용 캐릭터 저장 문자열이 바뀌지 않았다. 편집기 에셋 미리보기 그림 요청은 정상 동작으로 허용한다.

1440×1000 및 390×844 화면 캡처를 남겼다. 페이지 예외 0건. 운영의 기존 `/editor`, `/skill-editor`는 각각 HTTP 200 응답을 확인했다. 새 `/tools`의 운영 배포 완료는 별도로 확인하지 않았다.

```sh
CHROMIUM_PATH=/usr/bin/chromium node scripts/playtest-tools.mjs
```

기본 결과 경로: `/dev/shm/certz-tools`, 변경: `TOOLS_QA_OUT` / `TOOLS_QA_URL`.
