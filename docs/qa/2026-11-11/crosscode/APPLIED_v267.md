# 관찰한 전투 피드백 추가 적용 — v2.2.11 / vc267

기준 CERTZ/main `a018675`. 사용자 요청은 기존 Craft Anything 관찰을 게임에 적용하는 것이다. 이번 변경은 **기존 첫 전투 캡처로 직접 확인한 내용**을 적용했으며, 새로운 CrossCode 전투·보스 분석을 완료했다는 주장이 아니다.

## 관찰과 설계 선택

- 첫 공격 전 주변 적 HP바와 현재 필요한 입력 아이콘이 보인다. 근거: `ev_07590359676998b06619f93357da86ed4a510538c31bf7c9318f2475f2256c71`, `ev_a8001755bb428bc0191e581e8338385331c8138807f06004946eaea09a847c2b`. 캡처는 기존 `craft-evidence-v3.json.gz`에 있으므로 동일한 대용량 장부를 다시 복제하지 않았다. Craft finding에도 추가 기록했다.
- CERTZ는 첫 피격 때 HP바를 만들고, 풀 HP면 숨겨서 접근 중인 적이나 공격 준비 중인 적을 읽기 어려웠다. 기존 `Enemy.syncHpBar()`가 교전 중에도 같은 Rectangle 두 개를 만들고 재사용하도록 연결했다. 배회·도주·허수아비·보호 중인 풀 HP 적에는 추가 생성하지 않는다. 기존 피해·공격 타이밍·판정·AI 전이·상태이상·보상은 변경하지 않았다.
- 공격 준비/돌진 중에는 바를 주황색으로, 그 외에는 기존 빨간색으로 표시한다. 기절·유예·도주 때 공격 경고색을 사용하지 않는다. **주황색 선택은 우리 게임의 가독성 개선안**이며 참고작의 동일 색상·규칙을 복사한 것이 아니다.
- 캡처에서 표시 위치도 확인했다. 프레임 전체 높이에 투명 여백이 포함되면 HP바가 몸에서 멀어지므로, 이미 계산된 실제 판정 높이 `hitH`를 기준으로 배치한다. 적이 수련 중 정리되거나 죽을 때 기존 destroy 경로로 두 바를 함께 제거한다.
- 회피 수련의 돌진 버튼은 기존 `tutorial` prop으로 강조한다. 단계를 넘기면 해제되며 새 이벤트·상태·리스너는 없다. 화면의 잘못된 `Shift · 0초`와 접근성 안내를 모두 실제 `FREE_DASH.cooldownMs`에서 가져온다. 현재 값은 1초이고 돌진 동작·자원·쿨타임은 바꾸지 않았다. 동작 줄이기 설정에서는 강조 맥동을 생략한다.

## 검증과 재현

- 변경 전 실행 검사에서 풀 HP 교전 적의 HP바 미생성이 재현됐다. 변경 후 같은 검사가 통과한다.
- 전체 `npm test`: 609 통과 / 실패 0. 추가 검사는 첫 피격 전 표시, 배회 중 생성 방지, 경고색·기절·돌진·후딜, 피해에 따른 너비, 숨김·사망·수련 대기, 두 객체 재사용, 여백이 큰 아틀라스에서도 몸 기준 배치를 확인한다.
- `npx tsc --noEmit`, `npm run lint:strict`, `npm run build:next` 통과. 빌드에서 원본 런타임 에셋 보존 확인.
- `scripts/playtest-tutorial.mjs`: 새 캐릭터 생성 → 스토리 수련 → 중간 재접속 → 첫 피격 전 적 HP/공격 경고 → 실제 돌진 회피 → 버튼 강조 해제와 적 HP바 정리 → 의뢰·보상·수련 완료를 검증한다. PC는 방향+Shift, 터치는 회피에서 실제 두 손가락 조이스틱+돌진 버튼을 사용한다. 나머지 단계는 일반 키보드/UI를 병용한다. 상태·진행·전투 수치를 주입하지 않는다.
- PC/터치 결과·회피 화면은 `v267/`에 보관한다. 브라우저 검사에는 페이지 오류 0을 요구한다. 운영 배포 결과는 커밋 후 별도로 확인한다.

새 에셋·의존성·세이브 필드 없음. 기존 픽셀아트·정본 스토리·전직·기능 보존. CrossCode 조준·차지·후반 보스·전체 맵 및 CERTZ 장기 자연 성장 검증은 이번 범위에 포함하지 않는다.
