# SERTZ 궁극기 설계서 — 고유화 프로젝트 (vc194)

> 참고 영상: 메이플 전 직업 고르는 팁 (https://youtube.com/shorts/e_cl9yu60MM)
> 분석 결과 이 영상은 **궁극기 연출 쇼케이스가 아니라 직업 선택 가이드**다.
> 실제 전투 장면은 49~53초 5장뿐이며(보라 소용돌이 블랙홀형 광역기, 다색 폭발 파티클 + 다수 데미지 숫자),
> 나머지는 직업 목록·설명 자막이다. 따라서 연출 문법만 참고하고 수치는 SERTZ 자체 기준을 쓴다.

## 1. 현황 진단 (실측)

| 항목 | 수치 |
|---|---|
| 플레이 가능 직업 | **30** |
| 실제 궁극기 종류 (1차 `useSkill5`) | **13** (계열 폴백 5 + 4차 전용 8) |
| 연출 강도 프로파일 (`ultProfile`) | 수정 전 **15** → 20개 누락으로 **20직업이 완전 동일 연출** → 수정 후 **35**(계열+전용) |
| 2차 궁극기 종류 | 13 (동일 구조) |

### 발견한 두 가지 실제 결함
1. **`ultLayers.ts` PROFILES 누락** — 30직업 중 20직업이 `DEFAULT_PROFILE` 하나로 폴백.
   → warlord·paladin·eagleeye·tempest·stormbringer·chronicle·nightblade·duelist·
   warbringer·crusader·deadeye·skylord·arclord·eternal·shadowlord·blademaster·
   stormcaptain·powdermaster·seaking·dreadnought 가 **암전·히트스톱·흔들림·줌·VFX 키가 전부 동일**했다.
   → vc194에서 20개 프로파일 추가 완료(중복 0건 검증).

2. **궁극기 13종 / 직업 30** — 한 궁극기를 최대 6직업이 공유.
   특히 `stormbringer`(폭풍을 부르는 자)가 `mage`의 "종막 — 아르카나 대폭발"을 쓰고,
   `dreadnought`가 `pirate`의 "만조 — 대양 항로"를 쓴다. 정체성 불일치.

## 2. 남은 17직업 전용 궁극기 설계

각 항목: **전투 구조(다른 궁극기와 구별되는 핵심)** / 대표 한 장면 / 타임라인 요약

### 전사 계열 (묵직함 — 긴 암전, 강한 흔들림)

| 직업 | 궁극기명 | 전투 구조 | 대표 한 장면 |
|---|---|---|---|
| `berserker` | **광란 — 백절불굴** | 잃은 HP 비례 증폭. HP를 태울수록 연격 수가 늘어나는 **역설적 구조**(체력이 곧 자원) | 체력 30%에서 참격이 12연격으로 폭주, 화면 전체 핏빛 |
| `guardian` | **철벽 — 천년 방패** | 자신 주변 **보호막 성역**을 세우고 그 안의 적을 계속 밀어내는 **지면 장악형**(피해보다 통제) | 성역 경계가 황금빛으로 굳으며 적들이 파도처럼 밀려남 |
| `warlord` | **군림 — 대지 분쇄** | 전방 **3연 도약 강타**. 착지마다 지면이 갈라져 3개의 균열선이 남고, 그 위 적은 지속 경직 | 세 번의 착지로 십자 균열이 완성되는 순간 |
| `paladin` | **성역 — 심판의 빛** | 하늘에서 **빛기둥이 순차 낙하**(예고 후 타격). 아군은 회복, 적은 정화되는 **양면 구조** | 아홉 기둥이 차례로 내리꽂히고 마지막에 성검이 강림 |

### 궁수 계열 (정밀 — 짧은 암전, 긴 히트스톱, 작은 흔들림)

| 직업 | 궁극기명 | 전투 구조 | 대표 한 장면 |
|---|---|---|---|
| `sniper` | **일격 — 천리 관통** | **단일 대상 집중**. 3초 조준 후 한 발. 방어력 완전 무시 + 확정 크리티컬 | 조준선이 적 하나에만 고정되고, 발사 순간 화면이 0.3초 정지 |
| `windrunner` | **질풍 — 무한 궤적** | **이동하며 쏘는** 구조. 시전 중 이동 가능, 지나간 경로에 화살이 남아 재타격 | 캐릭터가 잔상으로 8개가 되어 화면을 가로지름 |
| `eagleeye` | **천안 — 표적 소거** | 화면 내 적 **전원에게 표식**을 찍고 동시 다발 저격(분산형) | 적 머리마다 붉은 표식이 점등된 뒤 일제히 관통 |
| `tempest` | **폭풍 — 연쇄 낙뢰** | 적에서 적으로 **연쇄**되는 낙뢰(최대 12회 도약). 밀집 대형에 강함 | 하나의 번개가 적 12명을 지그재그로 이어감 |
| `stormbringer` | **뇌신 — 천공 붕괴** | **지역 전체 뇌운**. 4초간 무작위 낙뢰 + 종결 뇌격. 광역 지속형 | 하늘이 검게 덮이고 빗줄기 사이로 뇌광이 쏟아짐 |

### 마법 계열 (발광 — 가장 긴 암전, 낮은 흔들림)

| 직업 | 궁극기명 | 전투 구조 | 대표 한 장면 |

|---|---|---|---|

## 3. 공통 구현 원칙

### 3.1 손대지 않는 것
- `useSkill5()` / `useSkill5b()`의 **기존 13종 케이스**는 그대로 유지(검증된 연출).
- `playUltLayers()`, `spawnUltIntroSig()`, `spawnUltFlourish()`, `cine3d()` 재사용.
- 신규 VFX 에셋 생성 없음 — 기존 `fx_*` 18종 + `spawnBurstAt/spawnPillar/spawnCrack/spawnSlash/spawnSpinSlash` 재사용.

### 3.2 신규 케이스가 지켜야 하는 것
- `rd(배율)`로만 피해 산출 → 기존 ultSlot 배율 체계 유지.
- 모든 `delayedCall` 콜백 첫 줄에 `if (this.state === "dead") return;` (사망 예외).
- 마지막에 공통 마무리(`state = "idle"`)가 이미 있으므로 **별도 해제 코드 금지**.
- 파티클/오브젝트는 `onComplete`에서 반드시 `destroy()` (모바일 메모리).
- 모바일: 한 번에 생성하는 오브젝트 ≤ 12, 전체 연출 ≤ 3.2초.

### 3.3 타임라인 기준 (직업군별)

| 군 | 발동 | 준비 | 전개 | 타격 | 복귀 |
|---|---|---|---|---|---|
| 전사 | 0~0.3s 자세 | 0.3~0.8s 무기 응집 | 0.8~1.8s 강타 | 1.8~2.4s 히트스톱 | 2.4s~ |
| 궁수 | 0~0.2s 조준 | 0.2~0.7s 시위 당김 | 0.7~1.2s 발사 | 1.2~1.6s 관통 | 1.6s~ |
| 마법 | 0~0.4s 룬 전개 | 0.4~1.4s 원소 응집 | 1.4~2.2s 방출 | 2.2~2.8s 폭발 | 2.8s~ |
| 도적 | 0~0.15s 은신 | 0.15~0.4s 도약 | 0.4~1.2s 연격 | 1.2~1.5s 마무리 | 1.5s~ |
| 해적 | 0~0.3s 조준 | 0.3~0.9s 장전 | 0.9~1.8s 포격 | 1.8~2.4s 충격파 | 2.4s~ |

## 4. 구현 순서 (승인 불필요 — 순차 진행)

1. `ultLayers.ts` 20프로파일 추가 — **완료**
2. `SKILL5_INFO`에 전용 17종 추가 + `TIER4_ULTIMATES` 확장
3. `resolveSkill5Of`가 17직업을 자기 키로 반환하도록 확장
4. `useSkill5()`에 17개 케이스 구현
5. `SKILL5B_INFO` + `useSkill5b()` 17개 케이스
6. `tsc --noEmit` + `eslint --max-warnings 0`
7. 검증 스크립트: 30직업 → 30궁극기 키 1:1 매핑 확인
