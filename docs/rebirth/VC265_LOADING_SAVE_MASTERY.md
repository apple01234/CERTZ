# vc265 / 2.2.9 — 로딩·세이브·전수 숙련·길 폭

기반: CERTZ main `6632911`. 기존 GameRoot → WorldScene → Player, 전직·장비·퀘스트·카메라·멀티플레이 및 모든 원본 에셋을 유지한다. 새로운 게임 에셋이나 의존성을 추가하지 않았다. 스토리를 새로 쓰거나 전수 사건을 창작하지 않는다.

## 동작

- 타이틀은 실제 배경 3개를 먼저 받는다. 월드 입장에서는 선택 외형 전체 동작, 해당 맵 몬스터/보스, 지형과 기본 전투 자료를 우선한다. 전체 아이템 아이콘·다른 외형·후반 연출은 동일 카탈로그에서 배경 로딩한다. 음악은 기존 지연 디코딩/LRU를 사용한다.
- 기존 Phaser4 재진입 로더 교착 우회 방식(네이티브 Image + TextureManager)을 재사용한다. 최대 6개 동시 요청, 파일당 8초·2회 시도, 단계당 30초 제한. 실패하면 명시적인 수동 재시도 화면을 표시한다. 뒤늦은 완료가 오류를 지우거나 미완성 월드에서 조작을 허용하지 않는다.
- 프레임이 실제로 존재할 때만 애니메이션을 등록한다. 먼저 idle이 등록되어도 나중 walk/attack 등록을 막지 않는다. 다른 맵에서 추가로 받은 몬스터·보스 애니메이션도 등록한다.
- 최종 전직 완료 문구는 실제 분기의 마지막 직업명을 사용한다.
- 숙련 추가 필요 횟수: **5 / 8 / 12 / 16 / 20 / 35 / 55 / 80 / 110 / 150**. 누적 **491회**, 최대 10단계·피해/치유 +20%. 첫 발동 pulse에만 시전당 1회. 준비 취소·차단 입력 제외. 상승 알림과 기존 전직 창을 사용하며 상시 게이지는 추가하지 않는다.
- 저장 v2: 이전 20회/단계 기록의 획득 단계와 단계 내 비율을 보존한다. 예: 19→4, 20→5, 39→12, 100→61, 200→491. 변환은 한 번만 적용한다.
- 원본을 별도 키에 먼저 백업한다. 백업/읽기 실패·미지원 미래 버전에서는 덮어쓰지 않는다. 캐릭터 수집이 일부 실패하면 부분 클라우드 업로드를 중단한다. 보조 호환 미러 실패는 주 저장 성공과 구분해 알린다.
- `memory-oath-v1`로 명시된 호환 RPG 저장만 스토리 진행을 정규화한다. 마커 없음·현행·알 수 없는 마커의 진행과 모든 소유 자산을 보존한다. 별도 캠페인 저장은 변환하지 않는다. `youngprincessv` 위치 전환은 스토리 정규화 이후 수행한다.
- 클라우드는 압축을 푼 활성/비활성 캐릭터 전체 버전을 확인한다. 구 클라이언트 GET/POST는 409와 업데이트 안내로 차단한다. 기존 암호화키·계정 DB를 초기화하지 않는다.
- 최신 사용자 요청: 주 도로 브러시를 미세 타일 2→6칸(약 192–240px)으로 확대했다. 공유 이동 가능 마스크에 맞춰 커브를 잘라 벽 안으로 도로를 그리지 않는다. 기존 넓은 통로 충돌 마스크와 맵별 구조를 유지한다.
- `/api/version`은 2.2.9/vc265 및 배포 SHA를 제공한다. Android 정적 export도 동일 Git SHA를 빌드에 전달한다.

## 검증과 증거

[실행 결과](../qa/2026-11-10/vc265/)는 로컬 QA이며 네트워크/기기 환경에 따라 시간은 달라진다.

- 실제 새 캐릭터 생성 → 프롤로그 → 이동/대화/공격/회피/스킬/획득/가방/의뢰/보고 → 튜토리얼 완료. 연습 중 새로고침 후 실제 이어하기. 브라우저 예외 0.
- 배포용 빌드에서 캐시 비활성, 약 4Mbps·지연 60ms Canvas: 타이틀 자료 81ms, 월드 자료 20,875ms, 월드 준비 20,995ms. 페이지 탐색/자동 메뉴 조작 포함 29,085ms. WebGL 월드 준비 2,213ms, 전체 6,367ms. 이 수치는 운영 Vercel에서 측정한 값이 아니다.
- 타이틀 glow, 월드 ground_meadow를 각각 강제 실패시킴 → 준비 전 진입 차단·오류 표시 → 실제 재시도 버튼으로 복구. 캐릭터 키 보존, 브라우저 예외 0.
- PC/실제 터치 돌진 취소, MP/쿨타임 유지, 경고 밝기 증가·정리, 실제 적 정상 타격, 숙련 4→5(1단계/+2%), 전직 창, 재접속 복원 확인. 전직/적 배치/초기 숙련 횟수는 폐기 가능한 QA fixture로 조정했다. 자연 플레이로 전 직업을 육성했다는 뜻은 아니다.
- 자동 검사 **601/601**, TypeScript·엄격 린트·배포용 빌드 통과.
- 전수 10종 각각 18초(총 180초 입력 구간)를 기존 쿨타임/MP 재생으로 측정: 기술당 실제 4–5회 발동, 0–1단계. 기본 캐릭터 스탯을 유지한 QA 전직 fixture이므로 자연 육성·장기 전투 밸런스 결론으로 확대하지 않는다.
- 전체 165개 챕터의 바닥/충돌 마스크와 월드 크기, 길 연결·여백·6칸 폭 검사 통과. 단위/회귀 검사는 백업 실패·구 저장·미래 버전·압축 클라우드·중복/취소/늦은 완료·애니메이션 후등록을 포함한다.
- 실행 명령: `npm test`, `npx tsc --noEmit`, `npm run lint:strict`, `npm run build:next`, `node scripts/playtest-tutorial.mjs`, `node scripts/playtest-reference-combat.mjs`, `node scripts/playtest-staged-loading.mjs`.

운영 클라우드 왕복·최종 배포 SHA·APK 서명/버전 검사는 배포 후 별도 결과로 기록한다. Android 실기기 플레이 및 전 스토리/보스 전체 완주는 이번 검증 범위가 아니다. 이전 `REFERENCE_AND_MASTERY.md`의 20회/단계 내용은 vc264 기록이며 현재 규칙은 이 문서가 대체한다.
