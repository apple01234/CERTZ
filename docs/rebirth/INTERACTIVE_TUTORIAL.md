# 월드 안에서 배우는 프롤로그와 기초 수련

기준: `2f6f8dd0dd1ffab09be88c2501cd9c38d409d54a` (독립 무쿨타임 돌진 포함).
2026-11-10 사용자의 튜토리얼 지시와 PROJECT REBIRTH의 기능 단위 검증 원칙을 적용한다. 전체 80항목 리메이크 완료 보고가 아니다.

## 분석과 재사용

실제 `/` 진입점은 GameRoot → 기존 WorldScene/Player다. CampaignRoot는 별도 호환 경로이므로 이 변경을 그쪽에만 구현하지 않았다. 기존 Tutorial, AutoCutscene/sceneCinematic, DialogueBox, InventoryPanel, 필드 NPC 의뢰, Drop, Enemy의 허수아비 및 실제 공격 상태기를 재사용했다. 별도 엔진이나 의존성을 추가하지 않았다.

코드 흐름·정본 대조·QA 분석을 분담한 뒤 서로 다른 파일을 수정했다. 분석에서 확인한 결함은 선택 콜백 뒤의 이전 dialogue:done이 다음 대사를 닫는 경합, 모바일 이벤트의 연출 가드 누락, 남은 스킬 입력 버퍼, buildSave에서 빠진 introSeen, 구 튜토리얼의 버튼 사용만으로 스킬 완료 처리, 재개 때마다 시작 물약을 주는 경로였다. 검은 프롤로그 깊이를 유지하라는 옛 테스트는 삭제된 렌더러의 구조를 고정하고 있어 새 행동 계약으로 교체했다.

## 이야기와 플레이 순서

정본 1.txt의 앞선 사건(디오의 괴롭힘 뒤 라일락의 구조 → 세 가지 사람 → 펜던트 → 레지스터의 수련)을 따른다. 기존 lilac00의 질문, 선택 ID haruWho, 후속 회상 계약은 유지한다. 다른 초안의 스칼렛 구조 장면으로 바꾸지 않는다. 첫 기술은 기본 검술 수련으로 표현하며 리엘의 복사/원소 순환이나 아리의 일섬을 앞당겨 해금하지 않는다.

1. 기존 절벽 맵의 배우·카메라·공용 대사창으로 오프닝을 진행하고 질문에 답한다.
2. 실제 이동으로 목표에 도착한 뒤, 특정 라일락 NPC에 다가가 NPC/채집으로 말을 건다.
3. 기존 startTransition을 통해 마을 수련터로 이동한다. 레지스터의 짧은 수련 연출 뒤 조작을 돌려준다.
4. 기본 공격을 수련 표적에 실제 명중시킨다.
5. 기존 적 AI의 공격 준비를 기다리고 움직여 범위 밖으로 나가 실제 빗나간 공격을 피한다. 독립 돌진도 사용할 수 있다.
6. 기본 스킬을 지정 표적에 명중시킨다. 허공 시전이나 MP/CD 실패만으로 진행하지 않는다.
7. 보급 물약에 직접 접근해 줍는다. 이 물약만 자석·펫 자동 획득에서 제외하며 일반 드롭은 그대로다.
8. 실제 가방의 물약 탭을 열어 획득 수량을 확인한 뒤 닫는다.
9. 레지스터에게 기존 선택지로 1마리 수련 의뢰를 수락한다. 실제 대상 처치와 보고/보상 지급은 각각 별도 단계다.
10. 짧은 마지막 대사 뒤 같은 마을 수련터에서 자유 플레이를 시작한다.

세 왕국, 인피니트보석 전쟁, 빛과 어둠·웨폰마스터의 배경은 기존 lilac00_open/war/close 데이터를 기록관의 선택 대화로 옮겼다. 필수 시작 화면에서 일괄 설명하지 않는다. 기록관은 수련 완료 후 수련터에 있으며 재방문 때도 생성된다.

## 상태, 저장, 안전한 복구

기존 Tutorial의 tutStep/tutorialDone을 유지하고 선택적 tutorialVersion=2를 추가했다. config 타입·create 복원·buildSave를 함께 변경했다. introSeen도 buildSave에 포함한다. 각 성공 단계와 전환은 저장하고, 완료·건너뛰기는 동일한 500G/HP·MP 물약 각3/뽑기권1 지급 및 완료 저장 경로를 한 번만 실행한다. 기존 필드 의뢰의 보고 보상은 지급과 함께 다음 단계를 저장하여 재접속 중복을 막는다.

명시적 신규 캐릭터(introSeen=false)와 버전2 진행 세이브만 새 튜토리얼에 진입한다. 버전 없는 구세이브와 이미 완료한 세이브는 저레벨이어도 강제로 되돌리지 않는다. 진행 중 의뢰는 현재 단계에서 기존 필드 의뢰 객체로 재구성하며 별도 퀘스트 엔진/저장 대장을 만들지 않는다.

수련 의뢰는 기존 퀘스트 창에서도 실제 목표를 확인한다. 이 실습에서만 창의 레벨 잠금을 우회하며, 일반 플레이의 기존 개방 조건은 유지한다.

원래 맵의 적은 삭제/처치하지 않고 잠시 정지·숨김 후 원래 활성/가시성/바디 상태로 복구한다. 수련 대상은 일반 필드 리스폰에 들어가지 않는다. 종료/씬 해제 시 소유 타이머·마커·연출 배우·입력 버퍼를 정리한다. 보급품을 줍지 않고 건너뛰어도 남지 않는다. 이미 실습한 가방·스킬·퀘스트의 기존 설명이 직후 중복 재생되지 않도록 기존 tutSeen도 기록한다.

## 입력과 UI

공유 canPlayerAction에서 컷씬·대화·패널·단계별 허용 동작을 판정한다. 키보드, EventBus 터치 입력, Player의 직접 스킬/돌진 호출이 같은 제한을 따른다. 기존 독립 돌진은 쿨타임0/무자원/무적 없음/충돌 판정을 보존한다.

컷씬에서는 일반 HUD·메뉴·패널·터치 전투 UI를 숨기고 공용 대사/선택지만 남긴다. 실습에서는 필요한 조작과 현재 목표만 보인다. 대화 선택은 세션당 한 번만 확정하며 동기적으로 다음 대사가 열리면 이전 done을 재전송하지 않는다. 키 반복으로 선택하거나 누른 키가 새 대사를 닫는 것도 막는다.
