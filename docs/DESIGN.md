# DESIGN — 무엇을 만드는가

## 한 줄 요약

SERTZ(이그드라실: 아뜰란티스) — 잠뜰TV 아뜰란티스 세계관의 모바일 세로→가로 대응 2D 액션 MORPG (Phaser 3 + React).

## 배경 / 목적

- 잠뜰TV 유튜브 콘텐츠 "아뜰란티스" 세계관의 2차 창작 게임. 주인공 세르츠가 요정 아리와 함께 세계수의 파편을 찾아 떠나는 모험.
- 대상: 모바일(터치) 우선, PC(키보드) 겸용. Capacitor 8로 APK 패키징까지가 최종 목표.
- 완성의 모습(합격기준) — **2026-08-28 달성**: 첫 플레이어가 튜토리얼 없이 마을→뿌리숲→알프헤임→보스 클리어까지 도달하고, 사냥→골드→상점→강화 순환이 끊기지 않으며, 기본 UX(음소거/회복)와 이어하기 무결성을 갖춘 상태.

## 기술 스택 / 실행 방법

- Next.js(React 19) + Phaser 3.90 + EventBus 브릿지 + Tailwind, Capacitor 8 (android)
- 실행: `npm run dev` (localhost:3000) / 검사: `npx tsc --noEmit`, `npx eslint src --max-warnings 0`
- 에셋: public/assets/ (외부 CC0/CC-BY — CREDITS.md 참조), 생성 스크립트 scripts/build_*.py

## 하드 제약 / 하면 안 되는 것

- **APK는 사용자가 "빌드"라고 말했을 때만** 만든다. 웹(dev) 검증까지가 기본 범위.
- 세이브 필드 추가 시 loadSave()에서 구 세이브 기본값 채우기 (사용자 세이브 파괴 금지).
- 테스트 오염 localStorage는 마지막에 반드시 clear() (사용자 신규 시작 보장).
- 외부 에셋 무단 라이선스 사용 금지 — CREDITS.md 누락 없이.
