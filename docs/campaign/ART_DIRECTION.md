# 기억의 서약 — 아트 기준과 출처

- 원본 픽셀 격자: **16×16**. 월드 캐릭터는 3배, 주요 보스는 5배. 최근접 필터만 사용한다.
- 타일·인물·소품·대화 초상: Kenney Tiny Town 1.0 / Tiny Dungeon 1.0 (CC0).
- 네비게이션 아이콘: `PixelIcons.tsx`의 자체 제작 16px 비트맵. 다른 벡터 아이콘팩을 섞지 않는다.
- UI: 잉크 `#171d2d`, 양피지 `#e9e1c9`, 금빛 `#dfc38b`, 보라 `#aba4d5`. 테마 색은 같은 명도 범위에서 변경한다.
- VFX: 저장소에 포함된 pixelfx(MIT)의 `holy/sunburst`. 128px 시트, nearest 필터, 원소술에만 사용한다. 기본 공격은 짧은 선으로 제한한다.
- 음악: 캠페인용 Web Audio 삼각파·완만한 음량 포락선으로 만든 자체 선율. 외부 녹음을 배포하지 않는다.
- 허용되지 않는 조합: Mystic Woods 파생 hero/chm/chf/cost, SPUM, 32rogues, 출처 불명 초상·AI 보스·3D 이펙트. 기존 소스의 에셋은 새 캠페인에서 로드하지 않는다.
- 원본 라이선스: `docs/assets_license/kenney_tiny-dungeon_LICENSE.txt`, `kenney_tiny-town_LICENSE.txt`, `vendor/pixelfx/LICENSE`.

에셋은 이름을 바꾸는 것으로 권리가 해결되지 않는다. 새 캠페인은 허용 목록만 배포한다. 저장소 전체의 과거 파일이 모두 권리 정리된 것으로 주장하지 않는다.
