# 정본과 각색

첨부 기획서의 **초기 1기 0~15화**가 정본이다. 후반의 ‘하루’ 리부트와 사건·주인공을 혼합하지 않는다. 플레이어는 연합의 전령/동행자이며, 주요 영웅의 역할을 빼앗지 않는다.

실명 대응표는 게임에 넣지 않는다. 라이선스의 저작자 표기는 삭제하지 않는다. 기존 사용자 입력 닉네임은 이 명칭 변경의 대상이 아니다.

## 장 구성

- 1부 15장: 왕립도서관 → 경고 → 함대의 패배 → 치료원 → 연합 → 보석의 자아 → 군단장 → 두 검사 → 리세아의 기억 → 네 원소의 문 → 저주와 흡수 → 마지막 장벽 → 엘리아 각성 → 시간의 수호자 → 복구와 선발대.
- 2부 10장: 원문 행성 순서에 따라 별문, 공학도시, 열차, 축제, 기계묘역, 전함, 꿈의 혜성, 가문/학원, 화원, 왕도. 원문 요약을 게임용으로 각색했다.
- 3부 9장: 일곱 원소 지역 → 성역 → 심장. 지역 설정 외에 완성 원고가 없어 **새 각색**이다.
- 2부 말미의 분리된 마도서를 3부의 동기로 연결한다. 3부는 영혼 흡수 대신 원소의 순환을 복원하며 종결한다. 죽은 동생을 부활시키거나 기억을 지우지 않는다.
- 선택지는 기억 수첩에 기록되며 결말을 분기하지 않는다.

각 장의 실제 대사·행동 목표·보상은 `src/game/campaign/catalog.ts`에 있다. 챕터는 레벨·반복 토벌·유료 재화로 잠그지 않는다.
