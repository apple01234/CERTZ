## 1. 기획서 핵심 요약

### 1-1. 세계관 (3개 세계)

| 세계 | 정체 | 주요 세력·가문 | 비고 |
|---|---|---|---|
| **라일락 월드** | 1기 무대. 3왕국→5왕국으로 재편된 보석을 둘러싼 세계 | 에델리오나(빛)·에스테반(물)·크렌렐브(대지)·이덴미르(눈)·에크레디트(자연) | 인피니트보석(라이트/다크니스) |
| **그랜드 플래닛** | 2기 무대. 파괴된 행성의 파편이 행성들로 재편 | 그래스트(우주)·데스티니(태양)·페이트(달)·카르리온(어둠)·아리아노(아트)·플래임(불)·오르페우스/페우스(마법)·셀리나(무기) | 빛과 어둠의 마도서 |

### 1-2. 힘의 체계 (핵심 — 게임 시스템으로 직결)

**웨폰마스터 등급 3분류**
| 등급 | 획득 방식 | 강함 |
|---|---|---|
| 순력 | 가문·혈통(천부적) | 중 |
| 혼력 | 원소의 구체가 선택 / 자의적 각성 | 하 |
| 초력(자력) | 초월의 경지에 도달 | 상 |

**초월자 5속성** — 빛 / 생명 / 시간 / 힘 / 마법
- 빛: 창조의 빛(빛), 파괴의 빛(어둠), 태양의 빛, 달의 빛, 우주의 빛
- 시간: 멈춰버린 시계, 뒤틀린 시계, 돌아간 시계, 운명의 시계, 반복되는 시계
- 생명: 자연의 생명(치유), 지배의 생명(절망), 생성의 생명(융합)
- 힘: 무술의 힘, 무기의 힘
- 마법: 주문의 마법, 주술의 마법

**원소 9종** — 불 / 물 / 바람 / 전기 / 땅 / 자연 / 얼음 / 빛 / 어둠
**어빌리티 계층** — 원소 어빌리티 < 영역 어빌리티 < 초월 어빌리티(마스터)

### 1-3. 스토리 (1기 = 라일락 월드)

주인공 **하루** — 고아. 절벽에서 **스칼렛**에게 구해지고 펜던트를 받는다.
→ 기사단 입단 시험 → 성 지하에서 **신비한 검**을 뽑음 → 마을 습격(사념체)
→ 양부모 사망 → 반란군 대장의 도움으로 **칼리야 왕국**으로 피신
→ 도사 **리엘**에게 수련 → **에벤트 왕국**에서 리안·아리·제르에게 원소·일섬·순환 습득
→ 연합 결성(에스테반 카르텔·아덴, 칼리야 시엘) → 고대의 재앙 **라시온** 부활
→ 초월자 **루시**와 스칼렛의 격전 → 최종 결전 → 15화 "New Beginning Not the End"

**핵심 주제**: 「세상에는 세 가지 사람이 있다 — 누군가를 죽이는 사람, 두려움에 도망치는 사람, 그 죽음에서 누군가를 살리는 사람」

## 3. 실행 계획

### Phase 1 (버그·규칙) — 먼저 완료

### Phase 2 (세계관 전면 개편) — 순서 고정

1. **데이터 계층**: 세계관 상수 신설 `src/game/lore.ts`
   - 3세계 / 5왕국 / 25가문 / 초월자 5속성 / 원소 9종 / 웨폰마스터 3등급
2. **지역·챕터 교체**: `stages.ts` CHAPTERS 9 → 15 (1기 15화 기준)
   - 라일락 5왕국 + 특수지역(도수관·이안페우스·무한의탑·영혼의군도·오션코멘)
3. **스토리·대사 교체**: `data.ts` DIALOGUES 110개 → 기획서 1기 15화 기반 재작성
4. **속성 상호작용 신설**: 원소 9종 × 상성표, 적 속성 부여, 데미지 배율
5. **스킬 전면 개편(#10)**: 클래스별 스킬을 원소 어빌리티/영역/초월 체계로 재설계
   - 마법사 계열 마법진 반복 제거(#16) — 스킬별 고유 이펙트
6. **보스 교체**: 스칼렛(1기 최종) · 라시온(재앙) · 군단장 6인
7. **건물·내부맵·NPC(12-b)**: 챕터별 건물 디자인 + 실내맵 + NPC + 기능
8. **UI 문구 정합**: 세계관 용어(이그드라실→라일락, 아홉왕국→5왕국 등) 전면 치환

### 유지 원칙
- 핵심 플레이 루프(사냥→성장→전직→보스) 유지
- 화면/UI 구조 유지
- 클래스 5계열 트리 유지(웨폰마스터 등급은 그 위에 얹는 축)
- 기획서 요구가 틀과 충돌하면 틀 우선 + 충돌 보고

## 4. 확인이 필요한 항목

1. **주인공 고정 여부** — 기획서 주인공은 '하루'. 현재는 플레이어가 이름을 짓는다. 이름은 유지하되 스토리상 '하루'로 고정할지.
2. **북유럽 명칭 잔재** — 알프헤임/무스펠헤임 등은 기획서의 그랜드플래닛 가문명(클로체스=스노리카 등)과 일부 겹친다. 전부 기획서 명칭으로 갈지.
3. **2기·3기 범위** — 이번 개편을 1기(라일락)까지로 할지, 2기(그랜드플래닛) 진입까지 포함할지.
