# 초상화 일치 컷씬 아틀라스 — 1차 적용 기록

기준 커밋: `1391b40c715c25b77fa30a07538bee7a8f03ed42`. 작업 대상은 CERTZ/main.

현재 컷씬의 화자·별칭을 대조하여 26개 신원을 만들고, 각자 16프레임 아틀라스와 같은 원본에서 추출한 초상화를 배포했다. 정본 등장인물과 기존 게임 안내 배역, 외형 명세가 없어 시각적으로 해석한 부분을 `public/assets/cutscene-cast/manifest.json`에 구분한다. 모든 기획서 등장인물을 이미 구현했다는 뜻이 아니다. 이후 보스 개편으로 추가되는 배역은 이 명세를 확장한다.

- 96×96 셀, 인물당 16프레임, 공통 발 기준점. 정면·측면·후면 대기/걷기와 대화·손 내밀기·부상·전투 준비.
- 원본 생성은 `image_gen.imagegen`. 프롬프트·원본 파일명은 `scripts/cutscene-cast-sources.json`, 원본 SHA-256은 인물별 atlas JSON에 있다. 원본 생성 파일은 `/workspace/generated_images`에 보존되며 런타임은 커밋한 정규화 PNG/JSON만 사용한다.
- 부팅 로더·애니메이션 등록·AutoCutscene·StoryCutscene·보스 대화형·일치하는 월드 NPC·DialogueBox에 실제로 연결했다. NPC 대화/선택/저장 키를 유지했다.
- 레지스터=시스터즈 발화 대표, 리엘=도사, 아리=아리스텔라. 라일락 연합 기록자는 라일락 본인과 분리했다.
- 아리는 여성 검사, 벨리카는 여성 번개 궁수·우편배달부로 수정했다. 하루는 강철 카타나, 해롤드는 무기 없음, 베로니카는 저주 지팡이를 따른다.
- 라일락은 페르온의 연인이다. 에테르를 깨닫는 인물은 하루다. 세계 복원으로 전쟁 사망자까지 부활하지 않는다. `2.txt`를 구판 `5.txt`보다 우선했다.
- 절벽 회상은 첫 필드만 야외 턱으로 바꾸고 어린 하루를 작게 배치했다. 포털 이펙트와 배우가 겹치지 않는 바닥을 찾으며, 연출 종료/스킵 때 숨긴 표시의 기존 상태를 복구한다. 부상 중인 루시를 걷게 하던 공통 이동은 제거하고 하루가 다가가게 했다.
- 기능 안내창은 마운트를 유지한 채 연출 중에 숨겨서 대사창을 가리지 않게 했다.

## 검증

- 전체 Node 테스트 537개 통과. 후속 배치/UI 수정 관련 검사 33개 통과, TypeScript·ESLint 통과.
- `scripts/playtest-cutscene-cast.mjs`: 새 로컬 세이브를 만들고 내부 QA용 챕터 점프로 실제 씬·카메라·대사 UI를 실행했다. 정상적인 전체 캠페인 플레이 완료 검증은 아니다.
- 브라우저에서 26개 아틀라스/416프레임과 초상화 26장 로드. 펜던트·벨리카·부상·아리/페르온 장면 촬영. 모바일 844×390 대사창 촬영. pageerror 및 해당 에셋 HTTP 실패 0.
- 로컬 결과: `/dev/shm/cast-qa/results.json`. 온라인 서비스와 APK 설치는 이 검증 범위 밖이다.

사용법: `node --experimental-strip-types --import ./tests/ts-resolve-hook.mjs scripts/playtest-cutscene-cast.mjs http://127.0.0.1:3100`.

사용자 후속 요청은 타일맵 전면 교체와 챕터에 맞는 보스 디자인/패턴 교체다. 이 파일은 그 전 단계의 완료 기록이며 후속 요청의 완료 보고가 아니다.
